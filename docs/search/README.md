# Research

Stage 1 of the planning of Vukem Video: what was studied before any decision, with its evidence. All sources were accessed on 2026-11-14.

## How to read it

- **Start with [`synthesis.md`](synthesis.md)**: the conclusions that changed the architecture, the main technical risks, and where each open question was settled.
- Then the thematic file of the subject you care about.
- [`notes/`](notes/) and [`projects/`](projects/) hold the raw material the thematic files were written from. They record what was found **before** the decisions; where a note recommends something an ADR decided differently, the ADR prevails. Each note says so in a banner at its top.

## Standard of evidence

Every claim is marked as one of:

- **FACT**: verified at the source (a repository, a release page, a specification, a measurement of ours), with the URL and the access date. Versions were read at the source, never recalled.
- **INFERENCE**: a conclusion drawn from facts, with the facts named.
- **OPINION**: a judgement of the architect, stated as such.

Critical facts were checked a second time by the architect; the list is [`notes/architect-verifications.md`](notes/architect-verifications.md). Every URL cited anywhere in this folder is in [`sources.md`](sources.md) (571 distinct URLs), with the files that cite it and what it supports. That index was generated by script and its count verified; the one-line descriptions were written from the citing lines and were not each rechecked against the page.

## Project profiles (`projects/`)

One file per project studied, with the same structure (what it is, licence, architecture, what to copy, what to avoid): `freecut`, `opencut`, `omniclip`, `filmcraft`, `reframe`, `voidcut` (open source editors), and `capcut`, `canva`, `clipchamp` (commercial references).

## Limits of this research

- Three spikes were run on a single Windows machine; nothing was measured on Linux or macOS.
- Commercial products were studied from their public documentation and behaviour, not from their code.
- Platform specifications (safe areas, limits) were found in official sources only for part of the platforms; the gaps are listed in `features-20-80.md` and `synthesis.md`.
- Legal questions about patents and licences are stated as researched facts and are not legal advice; the points that need a lawyer are listed in `licensing.md`.
