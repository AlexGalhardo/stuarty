Screenshots of Stuarty, captured on 2026-11-24 with a headless Chromium from a local `stuarty serve` of the repository
(release branch v0.55.0, whose build reports v0.54.0 in the sidebar), on a throwaway demo workspace made for the capture.
Every image below is made again by site/scripts/capture-landing.ts, which seeds the demo with the CLI and the HTTP API
of the product, takes the screens in both themes and encodes them (epic 95); the landing page and its alternative pages
use the same files.

Every image is a capture of the user interface at 1600 x 1000 px (home-mobile: the home in a 390 px wide window,
captured at 1600 x 3464 px), in the dark theme (name.*) and in the light theme (name-light.*), as .webp and .avif at
1600 px and, with the suffix -960, at 960 px. The 960 px files are the 1600 px capture scaled down. Nothing is drawn or
composed: no design file, render or mock-up. The files were encoded from the PNG captures with the repository's pinned
LGPL FFmpeg, carry no metadata, and are part of this repository under its MIT licence (LICENSE.md).

Media shown inside the screenshots: none from outside the repository. The clips, pictures and sounds of the demo
workspace were generated for the capture (gradients and sine tones made with the project's own FFmpeg). The demo
content is invented: the user alex, a Reel on five filming mistakes, its thumbnail, a blog post on natural light at
home, four posts on a local blog folder, a skill, a prompt and a memory note. It names no real person, brand or number, and it
holds no logo, testimonial or metric. The agent profiles and the home folder shown are the defaults of the machine that
captured them; no account, key or token of any user appears.
