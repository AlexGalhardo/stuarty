## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `read` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string` | yes | min length 1 |

## Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `asset_id` | `string` | yes | The asset to check: an asset of the project, ready.. min length 1 |
| `timeline_id` | `string` | no | The timeline of the project; required when the project has several. |
| `from` | `string` | no | Start of the range, a time; default 0s. |
| `until` | `string` | no | End of the range, exclusive; default the end of the timeline. |
| `track_id` | `string` | no | The visual track the clip will go on; tells whether the render needs alpha. |
