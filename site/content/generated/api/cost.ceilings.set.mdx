## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `admin` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Request body

Content type `application/json`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `currency` | `string` | yes | Three upper-case letters, for example USD.. min length 1 |
| `per_day_micros` | `integer (int64)` or `null` | no | The most that may be spent in one UTC day, in millionths of the currency unit. With neither limit, the ceiling is removed. |
| `per_item_micros` | `integer (int64)` or `null` | no | The most one action may cost, in millionths of the currency unit. |
| `project_id` | `string` | no | The project the ceiling is for; leave out for the whole workspace. |
