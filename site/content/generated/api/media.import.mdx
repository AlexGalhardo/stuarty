<RefMain>

Heavy call: shares the limit of 10 a minute per credential (E_RATE_LIMITED with Retry-After).

## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `media` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string` | yes | min length 1 |

## Request body

Content type `application/json`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `dry_run` | `boolean` | no | Checks the paths and limits only: the format is probed on the real import, so a file that is refused there (SVG, for one) still answers 202. |
| `files` | array of [`importFileIn`](/docs/api/schemas#importfilein) | yes | at least 1 items; at most 50 items |
| `info` | [`AssetInfo`](/docs/api/schemas#assetinfo) or `any` or `null` or `null` | no | Tags, the reuse mark and a description for the files of the call. |
| `origin` | [`Origin`](/docs/api/schemas#origin) or `any` or `null` or `null` | no | Where the files came from: kind imported (default), generated (provider and model), fetched_by_agent (source and rights_note) or rendered_externally (source). |
| `timeline_id` | `string` | no | The timeline of the project; required when the project has several. |
| `wait_ms` | `integer` | no | 0 to 25000: hold the call until the assets are ready. |
