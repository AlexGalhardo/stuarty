## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `read` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string` | yes | min length 1 |

## Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `timeline_id` | `string` | no | The timeline of the project; required when the project has several. |
| `from` | `integer (int64)` | no | The revision the diff starts from; or from_checkpoint. |
| `from_checkpoint` | `string` | no | The name of the checkpoint the diff starts from; or from. |
| `until` | `integer (int64)` | no | The revision the diff ends at; default the current one. |
