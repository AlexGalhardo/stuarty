## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `admin` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Request body

Content type `application/json`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `accepts` | array of `string` | yes | What the destination may receive: text, image, video, audio, metadata, document. |
| `endpoint` | `string` | yes | The URL the connector calls first: https, or http for a loopback host.. min length 1 |
| `hosts` | array of `string` | no | Further hosts the connection may reach, at most 16; the host of the endpoint is always allowed. |
| `kind` | `string` | yes | The kind of connection; test is the only one built in.. min length 1 |
| `label` | `string` | yes | 1 to 60 characters, shown to the person.. min length 1 |
| `secret` | `string` | yes | The credential of the destination, 1 to 16384 bytes. It goes into the vault and is in no answer.. min length 1 |
