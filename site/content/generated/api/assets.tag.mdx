## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `media` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `hash` | `string` | yes | sha256: and 64 hex digits, as the library lists it.. min length 1 |

## Request body

Content type `application/json`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `add` | array of `string` | no | Tags to add; at most 20 tags on a file. |
| `remove` | array of `string` | no | Tags to take off. |
