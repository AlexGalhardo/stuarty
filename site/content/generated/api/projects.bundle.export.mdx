<RefMain>

Heavy call: shares the limit of 10 a minute per credential (E_RATE_LIMITED with Retry-After).

## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `render` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string` | yes | min length 1 |

## Request body

Content type `application/json`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `include_log` | `boolean` or `null` | no | false leaves the history out, to share a project without it. Default true. |
| `timeline_id` | `string` | no | One timeline only (the format of releases up to 0.29.0); without it, the whole project. |
| `wait_ms` | `integer` | no | 0 to 25000: hold the call until the job is final. |
