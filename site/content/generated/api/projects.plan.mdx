## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `read` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string` | yes | min length 1 |

## Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `timeline_id` | `string` | no | The timeline of the project; required when the project has several. |
| `from` | `integer` | no | The first frame of the window, as a whole number of frames (not a time such as 1s); default 0. |
| `until` | `integer` | no | The end of the window in whole frames (not a time such as 1s), not included; at most 300 frames after from. Required. |
| `to` | `integer` | no | Deprecated alias of until (whole frames), removed at 1.0. |
| `rev` | `integer (int64)` | no | Must be the current revision when given. |
| `width` | `integer` | no | The width in pixels the preview draws at, 16 to 4096; bitmaps are rasterized at that scale. Default: the project width. |
