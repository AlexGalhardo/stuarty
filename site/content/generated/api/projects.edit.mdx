## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `edit` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string` | yes | min length 1 |

## Request body

Content type `application/json`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `base_revision` | `integer (int64)` | yes | The revision the batch was planned against. |
| `dry_run` | `boolean` | no |  |
| `idempotency_key` | `string` | no | 8 to 64 characters; the Idempotency-Key header is the same. |
| `operations` | array of [`Operation`](/docs/api/schemas#operation) | yes | at least 1 items; at most 200 items |
