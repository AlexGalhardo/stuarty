## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `edit` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Request body

Content type `application/json`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `description` | `string` | no | 64 to 1024 characters: what the project is, for whom, and what it makes. |
| `dry_run` | `boolean` | no |  |
| `fps` | `integer` or `string` | no | Deprecated, creates nothing: the frame rate is asked when a video is added. |
| `goal` | `any` | no | The SMART goal: specific, measurable, achievable, relevant and time_bound (16 to 280 characters each) and due (YYYY-MM-DD, today or later). |
| `height` | `integer` or `null` | no | Not accepted: the size comes from preset. |
| `id` | `string` | no | An id of your own; E_ID_EXISTS when taken.. pattern `^prj_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `name` | `string` | no | 4 to 32 letters, digits and single spaces. |
| `preset` | `string` | no | Deprecated, creates nothing: the size is asked when a video is added. |
| `width` | `integer` or `null` | no | Not accepted: the size comes from preset. |
