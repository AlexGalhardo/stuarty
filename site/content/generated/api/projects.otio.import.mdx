<RefMain>

Heavy call: shares the limit of 10 a minute per credential (E_RATE_LIMITED with Retry-After).

## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `edit` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Path parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string` | yes | min length 1 |

## Request body

Content type `application/json`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `allow_partial` | `boolean` | no | Import what the project can take when media is missing; default: refuse. |
| `base_revision` | `integer (int64)` | no | The revision the import is applied to. |
| `dry_run` | `boolean` | no |  |
| `path` | `string` | yes | An absolute path to an .otio file on the machine that runs the server.. min length 1 |
| `timeline_id` | `string` | no | The timeline of the project; required when the project has several. |
