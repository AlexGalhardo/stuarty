## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `edit` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Request body

Content type `application/json`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `connection_id` | `string` | yes | The connection to the provider that makes the images.. min length 1 |
| `count` | `integer` | no | How many images, 1 to 10; the default is 1. A model may make fewer at a time. The estimate counts all of them. |
| `dry_run` | `boolean` | no | true answers the job it would create, with its estimate, and writes and sends nothing. |
| `model` | `string` | yes | The model id, as provider:models lists it.. min length 1 |
| `project_id` | `string` | yes | The project the images belong to, prj_ and 10 characters.. min length 1 |
| `prompt` | `string` | yes | What to draw, 1 to 4000 characters.. min length 1 |
| `size` | `string` | no | Width and height in pixels joined by x; the default is 1024x1024. The model may make only some sizes. |
| `wait_ms` | `integer` | no | Wait up to this many milliseconds for the job to finish. |
