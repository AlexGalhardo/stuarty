## Authentication

Send the secret in the header `Authorization: Bearer <secret>`: the local token in local mode, an [API key](/docs/self-hosting/api-keys) in network mode. An API key needs the `read` scope; the local token has every scope. See the [API overview](/docs/api/overview) for both modes.

## Query parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `from` | `string` | yes | The start of the range: a date such as 2026-12-01 (the start of that day in zone), a local time read in zone, or an instant.. min length 1 |
| `to` | `string` | yes | The end of the range, exclusive, in the same forms as from.. min length 1 |
| `zone` | `string` | no | The IANA zone dates and local times are read in; empty is UTC. |
| `project_id` | `string` | no | Only the publications of one project. |
| `publications` | `boolean` | no | Also return the publications of the range, paged by limit and offset. |
| `limit` | `integer` | no | The page size of the publications, 1 to 500; the default is 100. |
| `offset` | `integer` | no | How many publications to skip. |
