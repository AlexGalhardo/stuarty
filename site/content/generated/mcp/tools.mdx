The server lists 20 tools. Each page has the input, the output, the errors, the safety notes and a real call.

| Tool | Title | Reads only | What it does |
| --- | --- | --- | --- |
| [`project_list`](/docs/mcp/tools/project_list) | List projects | yes | List projects, newest first. |
| [`project_create`](/docs/mcp/tools/project_create) | Create project | no | Create an empty project (no tracks; add them with edit). |
| [`project_get`](/docs/mcp/tools/project_get) | Read project | yes | Read a project as text: revision, settings, tracks top to bottom (the top one is drawn over the others), then items per track with times in seconds and frames. |
| [`project_trash`](/docs/mcp/tools/project_trash) | Trash or restore project | no | Move a project to the trash, or restore it with restore=true. |
| [`edit`](/docs/mcp/tools/edit) | Edit project | no | Change a project. |
| [`command_help`](/docs/mcp/tools/command_help) | Operation help | yes | Describe edit operations. |
| [`history`](/docs/mcp/tools/history) | History, undo and redo | no | Read the change log (action=list, newest first, with actor; actor, cursor, limit only for list), or undo or redo your own latest step (action=undo or redo, one step per call). |
| [`media_import`](/docs/mcp/tools/media_import) | Import media | no | Import local files into a project. |
| [`media_inspect`](/docs/mcp/tools/media_inspect) | Inspect media | yes | Describe an asset (asset_id) or list a project's assets, pending and failed included (no asset_id). |
| [`view`](/docs/mcp/tools/view) | View frame or sheet | yes | See the result. |
| [`lint`](/docs/mcp/tools/lint) | Lint project | yes | Check a project for problems: code, severity, item, message, hint. |
| [`job_start`](/docs/mcp/tools/job_start) | Start job | no | Start long work. |
| [`job_get`](/docs/mcp/tools/job_get) | Get job | yes | Get a job's state, progress and result (job_id). |
| [`job_cancel`](/docs/mcp/tools/job_cancel) | Cancel job | no | Cancel a queued or running job. |
| [`template`](/docs/mcp/tools/template) | Templates | no | Templates are projects with named slots. |
| [`font_import`](/docs/mcp/tools/font_import) | font_import | no | Add a TTF/OTF file to the font store. |
| [`connection`](/docs/mcp/tools/connection) | Connections | yes | List the destinations the user connected (id, kind, label, hosts, what each accepts, last use), or read one with id. |
| [`image`](/docs/mcp/tools/image) | Images | no | Images. |
| [`project_item`](/docs/mcp/tools/project_item) | Items | no | Project items. |
| [`library`](/docs/mcp/tools/library) | Library | no | The user's memory notes, skills and prompts (files). |
