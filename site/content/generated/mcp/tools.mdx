The server lists 17 tools. Each page has the input, the output, the errors, the safety notes and a real call.

| Tool | Title | Reads only | What it does |
| --- | --- | --- | --- |
| [`project_list`](/docs/mcp/tools/project_list) | List projects | yes | List projects, newest first. |
| [`project_create`](/docs/mcp/tools/project_create) | Create project | no | Create an empty project (add tracks with edit); returns its id and revision 0. |
| [`project_get`](/docs/mcp/tools/project_get) | Read project | yes | Read a project as text: revision, settings, tracks listed top to bottom (the top track is drawn over the others), then items per track with times in seconds and frames. |
| [`project_trash`](/docs/mcp/tools/project_trash) | Trash or restore project | no | Move a project to the trash, or restore it with restore=true. |
| [`edit`](/docs/mcp/tools/edit) | Edit project | no | Change a project. |
| [`command_help`](/docs/mcp/tools/command_help) | Operation help | yes | Describe edit operations. |
| [`history`](/docs/mcp/tools/history) | History, undo and redo | no | Read the change log of a project (action=list, newest first; actor, cursor, limit are for list only), or undo or redo your own latest step (action=undo or redo, one step per call). |
| [`media_import`](/docs/mcp/tools/media_import) | Import media | no | Import local files (absolute paths of video, audio or image) into a project. |
| [`media_inspect`](/docs/mcp/tools/media_inspect) | Inspect media | yes | Describe an imported asset as text (asset_id), or list every asset of the project with its state, pending and failed included (no asset_id). |
| [`view`](/docs/mcp/tools/view) | View frame or sheet | yes | See the result. |
| [`lint`](/docs/mcp/tools/lint) | Lint project | yes | Check a project for problems and get them as text: code, severity, item, message, hint. |
| [`job_start`](/docs/mcp/tools/job_start) | Start job | no | Start long work. |
| [`job_get`](/docs/mcp/tools/job_get) | Get job | yes | Get a job (job_id): state, progress, result. |
| [`job_cancel`](/docs/mcp/tools/job_cancel) | Cancel job | no | Cancel a queued or running job. |
| [`template`](/docs/mcp/tools/template) | Templates | no | Templates are projects with named slots. |
| [`font_import`](/docs/mcp/tools/font_import) | font_import | no | Add a TTF/OTF file to the font store. |
| [`project_item`](/docs/mcp/tools/project_item) | Items | no | Items of a project. |

The `edit` tool runs the [editing operations](/docs/mcp/tools/edit); each has a page.
