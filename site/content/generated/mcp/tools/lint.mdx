<RefMain>

Check a project for problems: code, severity, item, message, hint. Errors block export; run after edits, before export. Runs every rule. preset (see command_help domain=export) checks the fit to that export preset instead, over start..end.

## Behaviour

These are the annotations of the tool definition, the hints a client uses to decide whether to ask before a call. `lint` is listed by `tools/list`.

| Property | Value |
| --- | --- |
| Read only | yes |
| Destructive | no |
| Idempotent | yes |
| Reaches outside the workspace | no |

## Output

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)

A call over HTTP without credentials fails with `E_UNAUTHORIZED`, and too many calls with `E_RATE_LIMITED`. Both are in the [error codes](/docs/reference/error-codes).

## Safety

- Read only. Errors block an export; warnings do not.
