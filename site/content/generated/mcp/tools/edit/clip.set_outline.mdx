<RefMain>

Sets a contour of width pixels (0.5 to 100, default 4) in color (default #000000) around the visible shape of the clip, so a keyed subject gets a sticker-like border. Width is in project pixels. Replaces the current outline; outline null removes it. Works on clips and still images.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | A clip.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `outline` | `object` or `null` | yes | The outline, or null to remove it. |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
