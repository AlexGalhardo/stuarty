<RefMain>

Draws the pointer of the recording of the clip's asset, smoothed, as shape items on a Cursor track above the clip: the capture never contains the cursor. The path is the pointer events through a filter of time constant smoothing_ms (0 follows the raw path), sampled every keyframe_ms and mapped through the zoom and position the clip has when the command runs, so run it after recording.auto_zoom and again after changing the zoom or moving the clip; each run replaces the cursor items of the clip. style is dot or ring, size is in pixels of the frame and stays the same when the clip is zoomed; visible false removes the cursor. The positions come from the pointer events of the recording and are supplied by the service in resolved. The same events and options always give the same items.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `color` | `string` | no | A colour; default #FFFFFF. |
| `item_id` | `string` | yes | A clip of a screen recording.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `keyframe_ms` | `integer` | no | The time between two keyframes, 50 to 1000 ms. Default 100.; min 50; max 1000 |
| `size` | `number` | no | Pixels of the frame, 8 to 128. Default a fortieth of the frame height, at least 16.; min 8; max 128 |
| `smoothing_ms` | `integer` | no | Time constant of the smoothing, 0 to 2000 ms; 0 follows the raw path. Default 150.; min 0; max 2000 |
| `style` | `dot`, `ring` | no | Dot (default) or ring. |
| `visible` | `boolean` | no | False removes the cursor of the clip. Default true. |
