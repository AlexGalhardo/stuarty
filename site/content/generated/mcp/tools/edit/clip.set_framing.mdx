<RefMain>

Sets fit (cover, contain or none) and merges the given crop sides with the current ones. Each side is a fraction of the asset from 0 to 1; left plus right and top plus bottom must stay below 1. A side that has keyframes (crop_left, crop_top, crop_right, crop_bottom; see keyframe.set) cannot be set here.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `crop` | `object` | no | Sides to crop, fractions 0 to 1; sides not given keep their value. |
| `fit` | `cover`, `contain`, `none` | no | Cover (default), contain or none. |
| `item_id` | `string` | yes | A clip.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
