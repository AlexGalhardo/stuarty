<RefMain>

Reads the subtitle text (the service or the caller reads the file) and adds one caption for each cue on a visual track: the cue time is the caption time, rounded to frames, and its words share the duration in proportion to their character counts. Markup tags and line breaks are dropped. start moves every cue later by that length. The cues must not overlap each other or the items of the track.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `format` | `srt`, `vtt` | no | Srt or vtt; default: vtt when the text starts with WEBVTT. |
| `new_ids` | array of `string` | no | Ids for the created captions, in cue order. |
| `start` | `string` | no | A length added to every cue; default 0. |
| `text` | `string` | yes | The SRT or WebVTT text. |
| `track_id` | `string` | yes | A visual track that receives the captions.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
