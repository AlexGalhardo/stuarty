<RefMain>

Replaces the caption style of a visual track with a named style: clean_white, bold_pop, marker_yellow, soft_box, neon_night, editorial, mono_code, karaoke_pill, thick_outline, warm_glow, lower_bar, big_center, top_headline or ink_paper. Lengths scale with the shorter side of the project. Captions with their own style override keep it unless reset_overrides is true; effective.overridden_items lists them. caption.list_styles describes the styles.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `reset_overrides` | `boolean` | no | True clears the style override of the captions of the track. |
| `style` | `string`, one of 14 values | yes | The style id; caption.list_styles describes them. |
| `track_id` | `string` | yes | A visual track.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
