<RefMain>

Adds a composition: the timeline named by timeline_id, used as a clip (RF-083). Nothing is copied, so changing that timeline changes every composition that uses it. The default duration is the rest of the nested timeline from source_in. A timeline cannot contain itself at any depth, and compositions nest at most 4 deep.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `duration` | `string` | no | A length; default the rest of the nested timeline from source_in. |
| `fit` | `cover`, `contain`, `none` | no |  |
| `id` | `string` | no | pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `source_in` | `string` | no | Where in the nested timeline to start, as a length from its start; default 0s. |
| `start` | `string` | no | Absolute position; omitted, the end of the last item of the track (0s on an empty track). |
| `timeline_id` | `string` | yes | Another timeline of the same project.; pattern `^prj_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `track_id` | `string` | yes | A visual track.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
