<RefMain>

Moves a track to the top or the bottom, or directly above or below another track. Items are untouched.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `above` | `string` | no | pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `below` | `string` | no | pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `position` | `top`, `bottom` | no |  |
| `track_id` | `string` | yes | pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_INVALID_STATE`](/docs/reference/error-codes#e_invalid_state)

Scope `edit`. The scope is the one an API key needs in network mode. Run `stuarty command:help track.move` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
