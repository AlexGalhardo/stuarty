<RefMain>

Each break is the index of the word that starts a new line, from 1 to the word count minus 1, strictly increasing. An empty array clears the breaks.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `breaks` | array of `integer` | yes | Indexes of the words that start a new line, strictly increasing; [] clears. |
| `item_id` | `string` | yes | A caption.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
