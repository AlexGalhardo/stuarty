<RefMain>

Removes the asset from the project. It fails with E_IN_USE, listing the items, while an item uses it. The file stays in the content store.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `asset_id` | `string` | yes | The id of the asset to remove.; pattern `^ast_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_IN_USE`](/docs/reference/error-codes#e_in_use)

## Scope and phase

Scope `media`, phase `alpha`. The scope is the one an API key needs in network mode. Run `vukem-video command:help asset.remove` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
