<RefMain>

Adds an audio processor to the chain of a clip or audio item (item_id) or of a track (track_id). kind is eq, compressor, limiter, gate, deesser or noise_reduction; params are the values that differ from the default of the kind (units and ranges in SDD-004 7.1). The chain runs in order, so index matters; a track chain runs on the sum of the track.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `enabled` | `boolean` | no | False adds it switched off; default true. |
| `index` | `integer` | no | Where to insert, 0 to the length of the chain; default the end.; min 0 |
| `item_id` | `string` | no | A clip or audio item; give this or track_id.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `kind` | `eq`, `compressor`, `limiter`, `gate`, `deesser`, `noise_reduction` | yes | Eq, compressor, limiter, gate, deesser or noise_reduction. |
| `params` | `object` | no | Parameter values by name; the rest keep their default. |
| `track_id` | `string` | no | A track; give this or item_id.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
