<RefMain>

Removes the items. With ripple track, every later item on each affected track moves earlier by the length freed on that track; with ripple all, every later item on every track moves by the length freed, which requires the deleted items to cover one contiguous range; ripple all also moves the timeline markers after the range earlier by that length and removes those inside it (effective.markers_removed, markers_moved).

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_ids` | array of `string` | yes | at least 1 items; at most 200 items |
| `ripple` | `none`, `track`, `all` | no | None (default), track or all. |
