<RefMain>

The given keys are merged into the override the caption already has, so a later call that gives only a colour keeps the position set before; a null value removes one key. With replace true the object replaces the whole override. A null or \{\} style clears the override. highlight is none or word. The caption style of the track is not touched.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | A caption.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `replace` | `boolean` | no | Replace the whole override with style instead of merging. |
| `style` | `object` or `null` | yes | A partial CaptionStyle merged into the override (null removes a key), or null or \{\} to clear it. |
