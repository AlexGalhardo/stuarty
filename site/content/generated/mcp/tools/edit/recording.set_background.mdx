<RefMain>

Puts a colour or an image asset behind a screen clip, on a visual track named Background at the bottom of the stack, for the time the clip plays, and gives the clip a drop shadow (shadow, default true; false removes it). kind none removes the background and the shadow. Each run replaces the items of the clip's background. Use recording.apply_layout first: its padding leaves the room the background shows in. There is no gradient and no rounded corner: make a gradient as an image and use kind image.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `asset_id` | `string` | no | For image: an image asset.; pattern `^ast_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `color` | `string` | no | For color: a colour. Default #0F172A. |
| `item_id` | `string` | yes | The screen clip.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `kind` | `color`, `image`, `none` | yes | Color, image or none (removes the background and the shadow). |
| `shadow` | `boolean` | no | Draw a drop shadow under the clip. Default true. |
