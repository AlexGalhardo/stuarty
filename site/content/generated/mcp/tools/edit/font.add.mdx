<RefSplit>

<RefMain>

Names a font that is already stored by hash in the workspace as a family of the project, so that styles can use it. The family name must not be a bundled family. Adding to an existing family adds the weights and replaces the file of a weight it already has. The command never reads or stores a file; the service refuses a hash that the workspace does not hold.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `family` | `string` | yes | 1 to 60 characters: letters, digits, space, dot, hyphen, underscore; not a bundled family.; min length 1; max length 60 |
| `files` | array of `object` | yes | One file per weight, 1 to 9; a weight appears once.; at least 1 items; at most 9 items |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)

## Scope

Scope `media`. The scope is the one an API key needs in network mode. Run `stuarty command:help font.add` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
