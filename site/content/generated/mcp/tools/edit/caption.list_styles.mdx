<RefMain>

Changes nothing. The result lists each style of caption.apply_style with its name, a summary, its font family and the stored fields for a project whose shorter side is 1080 pixels.

## Arguments

This operation takes no arguments.

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)

## Scope

Scope `edit`. The scope is the one an API key needs in network mode. Run `stuarty command:help caption.list_styles` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
