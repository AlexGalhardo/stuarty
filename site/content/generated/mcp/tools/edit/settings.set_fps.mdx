<RefMain>

Rescales every time quantity q of the project to round(q * new / old), then repairs what rounding can break: durations that became 0, the source range, overlaps, keyframes, caption words, fades and transitions. effective.adjusted lists every item changed by a repair. A rate is 1 to 120 fps with a denominator of 1 or 1001.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `fps` | `any` | yes | "30", "30000/1001" or \{"num": 30000, "den": 1001\}; den is 1 or 1001, 1 to 120 fps. |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_INVALID_TIME`](/docs/reference/error-codes#e_invalid_time)

Scope `edit`, phase `alpha`. The scope is the one an API key needs in network mode. Run `stuarty command:help settings.set_fps` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
