<RefMain>

Places a screen clip and, for every layout but screen_only, a webcam clip by a named layout made for the project format (16:9, 1:1, 4:5 or 9:16): screen_only, pip (the camera over a corner of the screen, a circle by default), split (side by side in 16:9, one above the other in the others) or camera_focus (the camera fills the frame, the screen is a small inset). padding is a fraction of the shorter side of the frame, 0 to 0.25, left empty around everything. The result is ordinary fit, position, scale, crop and mask values, so every one stays editable, and no clip leaves the frame. The clip in front is put on the upper track. A clip whose x, y, scale, rotation or crop has keyframes cannot be laid out: apply the layout before recording.auto_zoom.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `camera_item_id` | `string` | no | The clip of the webcam take; required by every layout but screen_only, which refuses it.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `camera_shape` | `circle`, `rect` | no | For pip. circle (default) or rect. |
| `corner` | `top_left`, `top_right`, `bottom_left`, `bottom_right` | no | For pip and camera_focus. Default bottom_right. |
| `layout` | `screen_only`, `pip`, `split`, `camera_focus` | yes | Screen_only, pip, split or camera_focus. |
| `padding` | `number` | no | Fraction of the shorter side of the frame left empty around everything, 0 to 0.25. Default 0.; min 0; max 0.25 |
| `screen_item_id` | `string` | yes | The clip of the screen take.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
