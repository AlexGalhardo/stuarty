Adds a shape item with the given size in pixels before scale. Colours are hex or a template colour name like "$accent"; radius is for rounded_rect only. x and y default to the frame centre.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `duration` | `string` | yes | A length of at least 1 frame. |
| `fill` | `string` | no | A colour; default #FFFFFF. |
| `height` | `number` | yes | Pixels before scale, above 0 and at most 32768. |
| `id` | `string` | no | pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `radius` | `number` | no | Pixels, 0 or more; rounded_rect only. |
| `shape` | `rect`, `rounded_rect`, `ellipse` | yes |  |
| `start` | `string` | yes | A time with a unit: "12.5s", "375f" or "00:00:12.500" |
| `stroke_color` | `string` | no | A colour; default #000000. |
| `stroke_width` | `number` | no | Pixels, 0 or more. |
| `track_id` | `string` | no | A visual track; omitted, the highest visual track free over the item (an empty track you made for video counts; pass track_id to keep it clear), or a new one on top. effective.track_id names it.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `width` | `number` | yes | Pixels before scale, above 0 and at most 32768. |
| `x` | `number` | no |  |
| `y` | `number` | no |  |
