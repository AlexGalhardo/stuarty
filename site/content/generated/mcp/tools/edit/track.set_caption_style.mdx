<RefMain>

Sets the caption style of a visual track. The style is stored exactly as given, including keys equal to the default. A null value removes a key when merging. highlight is "none" or "word" (the active word is coloured with highlight_color). A bottom position anchors to the bottom of the safe area, not of the frame.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `replace` | `boolean` | no | Replace the whole style instead of merging. |
| `style` | `object` | yes | A partial CaptionStyle; null removes a key when merging. |
| `track_id` | `string` | yes | pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
