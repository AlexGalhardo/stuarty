<RefMain>

Sets a shadow drawn below the clip: the silhouette of its picture (a keyed subject keeps its cut-out shape) in color (default #000000), at opacity (0 to 1, default 0.5), moved by dx and dy pixels (-500 to 500, default 8) and softened by blur pixels (0 to 100, default 12). Lengths are project pixels. Replaces the current shadow; shadow null removes it. Works on clips and still images.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | A clip.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `shadow` | `object` or `null` | yes | The shadow, or null to remove it. |
