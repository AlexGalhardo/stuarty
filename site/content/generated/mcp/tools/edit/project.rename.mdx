<RefMain>

Sets the name of the project. The name is stored exactly as given, without trimming.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `name` | `string` | yes | The new name, 1 to 120 characters.; min length 1; max length 120 |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)

## Scope and phase

Scope `edit`, phase `prototype`. The scope is the one an API key needs in network mode. Run `vukem-video command:help project.rename` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
