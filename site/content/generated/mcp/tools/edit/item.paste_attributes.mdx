<RefMain>

Copies attribute groups from one item to 1 to 20 others: color, filter, blur, framing, transform (x, y, scale, rotation, opacity), blend, mask, flip, chroma_key, effects, audio (volume, denoise, voice). A group the target type does not have is skipped and listed in effective.skipped. Keyframes are not copied; a target whose animated property would be overwritten is refused.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `attributes` | array of `string` | yes | Groups to copy: color, filter, blur, framing, transform, blend, mask, flip, chroma_key, effects, audio. At least one, each once. |
| `from_item_id` | `string` | yes | The item to copy from.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `item_ids` | array of `string` | yes | The items to copy to, 1 to 20. |
