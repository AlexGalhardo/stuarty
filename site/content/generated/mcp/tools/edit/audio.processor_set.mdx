<RefMain>

Changes one processor of the chain of an item or a track. index is the 0-based place in the chain. params are merged with the current ones; enabled false keeps the processor but skips it.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `enabled` | `boolean` | no | True switches it on, false off. |
| `index` | `integer` | yes | The processor to change, 0-based.; min 0 |
| `item_id` | `string` | no | A clip or audio item; give this or track_id.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `params` | `object` | no | Values to change; the others stay. |
| `track_id` | `string` | no | A track; give this or item_id.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
