<RefMain>

Takes each listed item out of its link group. A group left with one item is dissolved, so the item that remains is unlinked too (listed in effective.also_unlinked).

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_ids` | array of `string` | yes | The items to take out of their link group. |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_INVALID_STATE`](/docs/reference/error-codes#e_invalid_state)

## Scope and phase

Scope `edit`, phase `beta`. The scope is the one an API key needs in network mode. Run `vukem-video command:help item.unlink` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
