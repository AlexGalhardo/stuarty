<RefMain>

Removes the marker at a frame; all removes every marker. With item_id it works on the markers of that item, beat markers included.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `all` | `boolean` | no | True removes every marker, instead of at. |
| `at` | `string` | no | The position of the marker to remove. |
| `item_id` | `string` | no | The item that holds the marker; all then clears its markers.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_INVALID_TIME`](/docs/reference/error-codes#e_invalid_time)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
