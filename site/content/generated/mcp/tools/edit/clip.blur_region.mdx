Hides part of the picture (an e-mail, a key, an address): adds a copy of the clip, limited to start and duration, on a Blur track above the clip, with a blur of radius and a rectangular mask of the region. x, y, width and height are fractions of the picture. The radius has a minimum, 1.5% of the shorter side of the project, and a default of 4%, so that the text cannot be read. A region that touches an edge of the picture is blurred as much as one in the middle. A feather is soft on both sides of the border of the region, so within half of it of an edge of the picture a little of the sharp picture shows and effective.near_edge is true: use feather 0 there. The clip is not changed; edit or delete the item named Blur region to change it.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `duration` | `string` | no | A length. Default up to the end of the clip. |
| `feather` | `integer` | no | Soft edge of the region in pixels, 0 to 200. Default 0.; min 0; max 200 |
| `height` | `number` | yes | Height of the region, a fraction of the picture.; min 0.001; max 1 |
| `item_id` | `string` | yes | A clip.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `new_id` | `string` | no | The id of the blur item.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `new_track_id` | `string` | no | The id of the track when one is made.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `radius` | `number` | no | Blur radius in pixels at project resolution, 1.5% of the shorter side to 100. Default 4%.; max 100 |
| `start` | `string` | no | Absolute start of the blur, inside the clip. Default the start of the clip. |
| `strength` | `strong`, `medium` | no | A named blur strength instead of a radius; strong is the default. |
| `track_id` | `string` | no | A visual track above the clip. Default a Blur track above it, made if there is none.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `width` | `number` | yes | Width of the region, a fraction of the picture.; min 0.001; max 1 |
| `x` | `number` | yes | Left edge of the region, a fraction of the picture.; min 0; max 1 |
| `y` | `number` | yes | Top edge of the region, a fraction of the picture.; min 0; max 1 |
