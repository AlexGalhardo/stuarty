<RefMain>

The item keeps its content. An unfilled media slot that still holds the placeholder asset cannot be unmarked.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |

## Errors

- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_SLOT`](/docs/reference/error-codes#e_slot)
- [`E_INVALID_STATE`](/docs/reference/error-codes#e_invalid_state)

## Scope and phase

Scope `edit`, phase `alpha`. The scope is the one an API key needs in network mode. Run `stuarty command:help slot.unmark` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
