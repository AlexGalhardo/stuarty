<RefMain>

Sets the value of x, y, scale, rotation, opacity, (clips and audio) volume or (clips) brightness, contrast, saturation, temperature, tint or hue at an absolute position inside the item, from its start to its end inclusive. When the property had no keyframe and at is after the start, its current static value becomes the first keyframe. The easing applies from this keyframe to the next. At most 100 keyframes per property.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `at` | `string` | yes | Absolute position inside the item, inclusive of its end. |
| `easing` | `linear`, `ease_in`, `ease_out`, `ease_in_out`, `hold` | no | From this keyframe to the next. Default linear. |
| `item_id` | `string` | yes |  |
| `property` | `string`, one of 12 values | yes |  |
| `value` | `number` | yes | Valid for the property: scale above 0 up to 20, opacity 0 to 1, volume 0 to 4. |
