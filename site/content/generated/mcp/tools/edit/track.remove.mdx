<RefMain>

Removes the track. A track with items is refused with E_NOT_EMPTY unless with_items is true, in which case its items are removed too.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `track_id` | `string` | yes | pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `with_items` | `boolean` | no | Remove the items of the track too. |

## Errors

- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_NOT_EMPTY`](/docs/reference/error-codes#e_not_empty)

## Scope

Scope `edit`. The scope is the one an API key needs in network mode. Run `stuarty command:help track.remove` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
