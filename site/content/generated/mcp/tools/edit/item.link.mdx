<RefMain>

Puts 2 to 20 clip, audio, text or shape items in one link group. item.move, item.trim and item.split on one of them apply the same change to the others, and a locked track refuses the edit that would change a linked item on it. An item belongs to one group; unlink it first to link it elsewhere.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | `string` | no | The id of the link group, lnk_ and 10 characters; generated when omitted.; pattern `^lnk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `item_ids` | array of `string` | yes | The items to link, 2 to 20. |
