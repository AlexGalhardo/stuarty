<RefMain>

Sets the given fields. hidden applies to visual tracks, the others to both kinds. locked refuses every edit of the items of the track (E_INVALID_STATE) until it is unlocked. solo plays only the soloed tracks: the picture of visual tracks when one is solo, and the sound of every track. volume is a factor from 0 to 4 on the volume of the items of the track; 1 clears it. magnet packs the items of the track from frame 0 with no gap, now and after every later edit (a locked track is not repacked).

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `hidden` | `boolean` | no | Visual tracks only. |
| `locked` | `boolean` | no | True refuses every edit of the items of the track until it is false again. |
| `magnet` | `boolean` | no | True keeps the items of the track packed from frame 0 with no gap, closing the gaps now and after every edit. |
| `muted` | `boolean` | no |  |
| `name` | `string` | no | The track name; "" clears it.; max length 60 |
| `solo` | `boolean` | no | True plays only the soloed tracks (the picture of visual tracks, the sound of all). |
| `track_id` | `string` | yes | pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `volume` | `number` | no | Factor on the volume of the items of the track, 0 to 4; 1 is neutral.; min 0; max 4 |
