<RefMain>

Sets the Gaussian blur radius in pixels at project resolution, 0 to 100; 0 removes the blur.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | A clip, text, caption or shape item.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `radius` | `number` | yes | Blur radius in pixels, 0 to 100; 0 removes the blur.; min 0; max 100 |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_TYPE_MISMATCH`](/docs/reference/error-codes#e_type_mismatch)

Scope `edit`, phase `beta`. The scope is the one an API key needs in network mode. Run `vukem-video command:help clip.set_blur` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
