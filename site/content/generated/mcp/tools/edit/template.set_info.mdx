<RefMain>

Sets the description and adds, replaces or (with null) removes named colours. A colour that a style, a shape or the background still refers to as "$name" cannot be removed. A document that has no template gets one.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `colors` | `object` | no | Name to #RRGGBB or #RRGGBBAA; null removes the name. |
| `description` | `string` | no | 0 to 500 characters.; max length 500 |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_IN_USE`](/docs/reference/error-codes#e_in_use)

## Scope and phase

Scope `edit`, phase `alpha`. The scope is the one an API key needs in network mode. Run `stuarty command:help template.set_info` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
