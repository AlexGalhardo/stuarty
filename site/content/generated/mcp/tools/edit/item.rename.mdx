<RefMain>

Sets the display name of the item; an empty name clears it.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | The item to label.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `name` | `string` | yes | The label, 0 to 120 characters; empty clears it.; min length 0; max length 120 |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)

## Scope and phase

Scope `edit`, phase `alpha`. The scope is the one an API key needs in network mode. Run `vukem-video command:help item.rename` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
