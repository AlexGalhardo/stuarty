<RefMain>

Adds a copy of the item at start, on the same track or another track of the same kind. Keyframes, words and the name are copied; the slot mark is not. Without start the copy goes to the first free position at or after the end of the source on the target track. With start it fails when the copy would overlap an item of the target track.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | The item to copy.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `new_id` | `string` | no | The id of the copy.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `start` | `string` | no | Absolute start of the copy; default the first free position after the source. |
| `track_id` | `string` | no | The track of the copy; default the source's track.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
