<RefMain>

Sets the given adjustments, rounded to 3 decimals; a value equal to the default (brightness 0, contrast 1, saturation 1, temperature 0, tint 0, hue 0) clears the stored one. Positive temperature is warmer, positive tint is more magenta, hue rotates the colours in degrees. lut_asset is the id of a lut asset (a .cube file) and lut_intensity how much of it is mixed in, 0 to 1, default 1; lut_intensity 0 removes the lookup table. hsl bands (red, orange, yellow, green, cyan, blue, purple, magenta: hue, saturation, lightness, -1 to 1), wheels (shadows, midtones, highlights: hue 0 to 360, amount 0 to 1, luma -1 to 1) and curves (master, red, green, blue: 2 to 8 points of x and y from 0 to 1) each replace what they name and a neutral one removes it.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `brightness` | `number` | no | -1 to 1; default 0.; min -1; max 1 |
| `contrast` | `number` | no | 0 to 2; default 1.; min 0; max 2 |
| `curves` | `object` | no | Tone curves: master, red, green, blue. |
| `hsl` | array of `object` | no | Bands of colour ranges, up to 8; a given range replaces its band, a neutral band removes it. |
| `hue` | `number` | no | -180 to 180 degrees; default 0.; min -180; max 180 |
| `item_id` | `string` | yes | A clip.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `lut_asset` | `string` | no | Id of a lut asset to grade the clip with.; pattern `^ast_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `lut_intensity` | `number` | no | 0 to 1; default 1; 0 removes the lookup table.; min 0; max 1 |
| `saturation` | `number` | no | 0 to 2; default 1.; min 0; max 2 |
| `temperature` | `number` | no | -1 (cooler) to 1 (warmer); default 0.; min -1; max 1 |
| `tint` | `number` | no | -1 (greener) to 1 (more magenta); default 0.; min -1; max 1 |
| `wheels` | `object` | no | Colour wheels of shadows, midtones and highlights. |
