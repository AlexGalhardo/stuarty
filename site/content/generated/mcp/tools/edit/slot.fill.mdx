<RefMain>

Give exactly one of asset_id (media slot), text (text slot) or words (caption slot). A media slot with duration policy fit keeps its duration and needs an asset long enough; with stretch_timeline it takes the rest of the asset and the later items of every track follow.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `asset_id` | `string` | no | For a media slot.; pattern `^ast_([0123456789abcdefghjkmnpqrstvwxyz]{10}\|placeholder)$` |
| `name` | `string` | yes | The slot name. |
| `source_in` | `string` | no | With asset_id only. Default "0s". |
| `text` | `string` | no | For a text slot.; min length 1; max length 2000 |
| `words` | array of `object` | no | For a caption slot: words with times relative to the caption, as lengths. |
