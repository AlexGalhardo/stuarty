<RefMain>

Makes a new timeline of the project from the selected items (same tracks, same frame size and rate, starting at frame 0) and replaces them with one composition of it, on the top-most visual track of the selection, for the same frames. The inverse puts the items back; the new timeline stays in the project.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | `string` | no | The id of the composition item.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `item_ids` | array of `string` | yes | The items to move, each once.; at least 1 items; at most 100 items |
| `name` | `string` | no | The name of the new timeline; default Composition.; min length 1; max length 120 |
| `timeline_id` | `string` | no | The id of the new timeline.; pattern `^prj_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
