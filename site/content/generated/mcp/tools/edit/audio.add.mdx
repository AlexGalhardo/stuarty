Adds an audio item. The default duration is the rest of the asset from source_in. The reserved asset ast_placeholder creates a template slot holder and needs an explicit duration.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `asset_id` | `string` | yes | An audio asset, a video asset with audio, or ast_placeholder in a template.; pattern `^ast_([0123456789abcdefghjkmnpqrstvwxyz]{10}\|placeholder)$` |
| `duration` | `string` | no | A length; default the rest of the asset. |
| `id` | `string` | no | pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `source_in` | `string` | no | Offset into the asset; default 0s. |
| `start` | `string` | no | Absolute position; omitted, the end of the last item of the track (0s on an empty track). |
| `track_id` | `string` | yes | An audio track.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
