<RefMain>

Adds a clip. The default duration is the rest of the asset from source_in, or 5 seconds for an image. The reserved asset ast_placeholder creates a template slot holder and needs an explicit duration.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `asset_id` | `string` | yes | A video or image asset, or ast_placeholder in a template.; pattern `^ast_([0123456789abcdefghjkmnpqrstvwxyz]{10}\|placeholder)$` |
| `duration` | `string` | no | A length; default the rest of the asset, or 5s for an image. |
| `fit` | `cover`, `contain`, `none` | no |  |
| `id` | `string` | no | pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `source_in` | `string` | no | Offset into the asset; default 0s; omit for an image. |
| `start` | `string` | no | Absolute position; omitted, the end of the last item of the track (0s on an empty track). |
| `track_id` | `string` | yes | A visual track.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
