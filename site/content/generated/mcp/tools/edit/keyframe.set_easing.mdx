<RefMain>

Gives the keyframe at the absolute position a named easing (easing), a custom cubic Bezier curve (bezier: x1, y1, x2, y2; x1 and x2 from 0 to 1, y1 and y2 from -2 to 3) or a named Bezier preset (preset: in, out, in_out, back, overshoot, stored as its four numbers). Exactly one of the three. The value and the time of the keyframe do not change. Works for every animatable property, crop and mask included.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `at` | `string` | yes | Position of an existing keyframe on the project timeline. |
| `bezier` | array of `number` | no | X1, y1, x2, y2 of a cubic Bezier curve: x1 and x2 from 0 to 1, y1 and y2 from -2 to 3.; at least 4 items; at most 4 items |
| `easing` | `linear`, `ease_in`, `ease_out`, `ease_in_out`, `hold` | no | A named easing. Exactly one of easing, bezier and preset. |
| `item_id` | `string` | yes | pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `preset` | `in`, `out`, `in_out`, `back`, `overshoot` | no | A named Bezier curve, stored as its four numbers. |
| `property` | `string`, one of 21 values | yes |  |
