<RefMain>

Replaces the text, merges a partial style into the stored one (null removes a key), or empties the style first with reset_style. At least one of text, style and reset_style is required.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | A text item.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `reset_style` | `boolean` | no | Empty the stored style before applying style. |
| `style` | `object` | no | A partial TextStyle, merged; null removes a key. |
| `text` | `string` | no | min length 1; max length 2000 |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_TYPE_MISMATCH`](/docs/reference/error-codes#e_type_mismatch)
- [`E_FONT_UNKNOWN`](/docs/reference/error-codes#e_font_unknown)

## Scope and phase

Scope `edit`, phase `prototype`. The scope is the one an API key needs in network mode. Run `vukem-video command:help text.set` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
