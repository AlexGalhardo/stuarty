<RefMain>

Adds a visual or audio track. A visual track goes on top by default and an audio track at the bottom, below the visual ones; position top or bottom, above or below another track places it elsewhere. The first track in the order is the top layer. The document keeps tracks in a map by id, so read the stacking from the order field (ascending, the smallest is the top layer), not from the position of a track in the listing.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `above` | `string` | no | Place the track directly over this track.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `below` | `string` | no | Place the track directly under this track.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `id` | `string` | no | pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `kind` | `visual`, `audio` | yes |  |
| `name` | `string` | no | max length 60 |
| `position` | `top`, `bottom` | no | Top (default) or bottom. |
