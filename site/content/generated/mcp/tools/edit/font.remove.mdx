<RefMain>

Removes the family from the fonts of the project. A family that a text style, a caption style or a track still uses cannot be removed. The font files stay in the workspace.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `family` | `string` | yes | A user family of the project. |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_IN_USE`](/docs/reference/error-codes#e_in_use)

## Scope

Scope `media`. The scope is the one an API key needs in network mode. Run `stuarty command:help font.remove` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
