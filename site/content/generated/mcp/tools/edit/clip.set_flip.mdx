<RefMain>

Sets the mirror of an item: horizontal flips left to right, vertical flips top to bottom. A side not given keeps its value; false clears it. Works on clip, text, caption and shape items.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `horizontal` | `boolean` | no | Mirror left to right. |
| `item_id` | `string` | yes | A visual item.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `vertical` | `boolean` | no | Mirror top to bottom. |
