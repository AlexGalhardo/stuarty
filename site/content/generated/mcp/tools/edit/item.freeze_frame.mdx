<RefMain>

Splits the clip at a timeline frame and puts between the two parts a new clip that shows the source frame at that point for duration (default 3s), with no sound. The right part and the later items of the track move later by duration; other tracks are untouched. The freeze frame has no keyframes. Not for linked items or items with a speed curve.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `at` | `string` | yes | Absolute frame inside the clip whose picture is held. |
| `duration` | `string` | no | How long the frame is held; default 3s. |
| `freeze_id` | `string` | no | Id for the freeze frame item.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `item_id` | `string` | yes | A clip of a video asset.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `new_id` | `string` | no | Id for the right part of the split.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
