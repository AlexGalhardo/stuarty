<RefMain>

Replaces the text of the word at index; timing is untouched. An empty text removes the word and leaves a gap. The only word of a caption cannot be removed.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `index` | `integer` | yes | 0-based index of the word.; min 0 |
| `item_id` | `string` | yes | A caption.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `text` | `string` | yes | The new text, 0 to 80 characters, no whitespace; empty removes.; min length 0; max length 80 |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_TYPE_MISMATCH`](/docs/reference/error-codes#e_type_mismatch)
- [`E_INVALID_STATE`](/docs/reference/error-codes#e_invalid_state)

## Scope and phase

Scope `edit`, phase `alpha`. The scope is the one an API key needs in network mode. Run `vukem-video command:help caption.edit_word` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
