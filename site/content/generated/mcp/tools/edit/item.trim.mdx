<RefMain>

Moves an edge to an absolute position and keeps the source range, the keyframes and the caption words consistent. The end edge is exclusive: it is the first frame after the item. With ripple track the later items of the track follow the change in length (a start trim then keeps the start of the item). With roll true the touching edge of the neighbouring item moves to the same frame (a roll edit).

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `edge` | `start`, `end` | yes |  |
| `item_id` | `string` | yes | pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `ripple` | `none`, `track` | no | None (default) or track: the later items of the track follow the change in length; with the start edge the item keeps its start. |
| `roll` | `boolean` | no | Roll edit: the touching edge of the neighbouring item moves to the same frame, so the cut moves and nothing else changes. Not with ripple track. |
| `to` | `string` | yes | Absolute position of the edge; the end is exclusive. |
