<RefMain>

Adds a marker at a frame of the timeline, with an optional label of up to 60 characters. With item_id the marker belongs to that item (at must fall inside it) and moves with it, like the beat markers of audio.mark_beats. At most 200 markers on the timeline and on each item; one marker per frame. Markers have no effect on the picture or the sound.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `at` | `string` | yes | The position on the timeline. |
| `item_id` | `string` | no | An item to mark instead of the timeline; at must then fall inside it.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `label` | `string` | no | Up to 60 characters; default none.; max length 60 |
