<RefMain>

Marks each click of the recording of the clip's asset with a short effect, a shape item on a Click highlight track above the clip: style ring (a ring that fades), wave (a ring that grows while it fades) or pulse (a disc that shrinks while it fades); none removes the highlights. Each lasts duration_ms and is cut short by the next click. It is placed through the zoom and position the clip has when the command runs, so run it after recording.auto_zoom and again after changing the zoom or moving the clip; each run replaces the highlights of the clip. The clicks come from the pointer events of the recording and are supplied by the service in resolved. The same clicks and options always give the same items.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `color` | `string` | no | A colour; default #FFC400. |
| `duration_ms` | `integer` | no | How long one highlight lasts, 200 to 2000 ms. Default 600.; min 200; max 2000 |
| `item_id` | `string` | yes | A clip of a screen recording.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `size` | `number` | no | Pixels of the frame, 16 to 400. Default a twelfth of the frame height.; min 16; max 400 |
| `style` | `ring`, `wave`, `pulse`, `none` | no | Ring (default), wave, pulse, or none to remove the highlights. |
