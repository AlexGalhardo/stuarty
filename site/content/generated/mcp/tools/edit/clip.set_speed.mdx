<RefMain>

Sets either speed, from 0.25x to 4x, or curve, 2 to 8 points \{t, speed\} (speed is text like "0.5x") with t the fraction of the item from 0 to 1 (first 0, last 1) and a linear ramp between points; a speed clears the curve. Rescales the duration, the fades, the transitions and the keyframes by the ratio of the old to the new mean speed. With ripple track the later items of the track follow the change in length. Captions linked to the clip are listed, not changed. reverse true plays the same source range backwards (false restores it), alone or with a speed or a curve.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `curve` | array of `object` | no | Speed ramp: 2 to 8 points, linear between them, first t 0 and last t 1. Not with speed. |
| `item_id` | `string` | yes | A clip of a video asset, or an audio item.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `reverse` | `boolean` | no | True plays the source range backwards; false plays it forwards. |
| `ripple` | `none`, `track` | no | None (default) or track: shift the later items of the track. |
| `speed` | `any` | no | "1.5x" (up to 3 decimals) or \{"num": 3, "den": 2\}; 1/4 to 4. Not with curve. |
