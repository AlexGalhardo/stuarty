Adds a caption. Give either words (times relative to the caption, as lengths) or text with a duration: the text is split on whitespace and the words share the duration in proportion to their character counts. x and y are used when the caption style position of the track is custom.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `duration` | `string` | no | A length; with text only. |
| `id` | `string` | no | pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `linked_item` | `string` | no | The clip whose speech this transcribes; it need not exist. |
| `start` | `string` | yes | A time with a unit: "12.5s", "375f" or "00:00:12.500" |
| `text` | `string` | no | Text to split on whitespace; needs duration. |
| `track_id` | `string` | no | A visual track; omitted, the highest visual track free over the item (an empty track you made for video counts; pass track_id to keep it clear), or a new one on top. effective.track_id names it.; pattern `^trk_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `words` | array of `object` | no | Words with times relative to the caption, as lengths. |
| `x` | `number` | no |  |
| `y` | `number` | no |  |
