Sets source_in, the offset into the asset where the item starts reading (a slip edit). The start, the duration, the keyframes and the neighbours do not change. The source range must stay inside the asset.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | A clip or audio item of a video or audio asset.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `source_in` | `string` | yes | The new offset into the asset where the item starts reading. |

## Errors

## Scope and phase

Scope `edit`, phase `beta`. The scope is the one an API key needs in network mode. Run `vukem-video command:help item.slip` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
