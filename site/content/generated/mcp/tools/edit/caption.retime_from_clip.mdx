<RefMain>

Maps the transcript words of the visible range to the timeline again and gives them to the linked captions in order, each taking as many words as it has. Edited texts are kept when the word count is unchanged. The transcript is supplied by the service in resolved.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `clip_item_id` | `string` | yes | A clip of a video asset with audio, or an audio item.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `resolved` | `object` | no | Filled by the service from the transcript of the asset; never sent by a caller. |

Scope `edit`, phase `alpha`. The scope is the one an API key needs in network mode. Run `vukem-video command:help caption.retime_from_clip` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
