<RefMain>

enabled false keeps the item, its place and its settings, and makes the preview, the export and the audio mix ignore it; true turns it back on. Works on every item type.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `enabled` | `boolean` | yes | False turns the item off, true turns it on. |
| `item_id` | `string` | yes | Any item.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)

## Scope and phase

Scope `edit`, phase `beta`. The scope is the one an API key needs in network mode. Run `stuarty command:help item.set_enabled` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
