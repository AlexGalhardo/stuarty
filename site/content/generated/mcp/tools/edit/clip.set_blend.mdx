<RefMain>

Sets one blend mode of the fixed list (normal, multiply, screen, overlay, add). normal is the default and clears the stored one. Works on clip, text, caption and shape items.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | A visual item.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `mode` | `normal`, `multiply`, `screen`, `overlay`, `add` | yes | Normal, multiply, screen, overlay or add. |
