<RefMain>

Removes the keyframe at the absolute position. The last keyframe of a property writes its value into the static field.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `at` | `string` | yes | Position of the keyframe on the project timeline, from the item start to its end inclusive. |
| `item_id` | `string` | yes | pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `property` | `string`, one of 21 values | yes |  |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_INVALID_TIME`](/docs/reference/error-codes#e_invalid_time)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_TYPE_MISMATCH`](/docs/reference/error-codes#e_type_mismatch)

## Scope and phase

Scope `edit`, phase `alpha`. The scope is the one an API key needs in network mode. Run `stuarty command:help keyframe.remove` for the same description from the binary, or call the [`command_help`](/docs/mcp/tools/command_help) tool.
