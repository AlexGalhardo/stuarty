<RefMain>

Sets the given properties, rounded to 3 decimals. Scale 1, rotation 0 and opacity 1 clear the stored value. A property that has keyframes cannot be set; use keyframe.set or keyframe.clear.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | A clip, text, caption or shape item.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `opacity` | `number` | no | 0 to 1.; min 0; max 1 |
| `rotation` | `number` | no | Degrees clockwise. |
| `scale` | `number` | no | Uniform scale, greater than 0 and at most 20.; max 20 |
| `x` | `number` | no | Centre of the item in pixels. |
| `y` | `number` | no | Centre of the item in pixels. |
