<RefMain>

Makes the pixels near a colour transparent. similarity (0 to 1, default 0.3) is how far from the colour a pixel is still removed, smoothness (0 to 1, default 0.1) the soft edge beyond it and spill (0 to 1, default 0) how much of the colour is taken out of the pixels that stay. On a clip that is already keyed, values not given keep their current value. color null removes the key. Values are rounded to 3 decimals.

## Arguments

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `color` | `string` or `null` | yes | The colour to remove, #RRGGBB, or null to remove the key.; pattern `(^#([0-9A-Fa-f]{6}\|[0-9A-Fa-f]{8})$)\|(^\\$[a-z][a-z0-9_]{0,39}$)` |
| `item_id` | `string` | yes | A clip.; pattern `^itm_[0123456789abcdefghjkmnpqrstvwxyz]{10}$` |
| `similarity` | `number` | no | 0 to 1; default 0.3, or the current value.; min 0; max 1 |
| `smoothness` | `number` | no | 0 to 1; default 0.1, or the current value.; min 0; max 1 |
| `spill` | `number` | no | 0 to 1; default 0, or the current value.; min 0; max 1 |
