<RefMain>

Describe edit operations. Without name: one line each. With name (e.g. item.split): description, args schema, example, error codes. Read it before using an unfamiliar operation. domain=export: presets and codecs.

## Behaviour

These are the annotations of the tool definition, the hints a client uses to decide whether to ask before a call. `command_help` is listed by `tools/list`.

| Property | Value |
| --- | --- |
| Read only | yes |
| Destructive | no |
| Idempotent | yes |
| Reaches outside the workspace | no |

## Input

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `name` | `string` | no |  |
| `domain` | `video`, `image`, `export` | no |  |

## Output

A result has a text block, written for the model, and structured content with these members.

| Member | Type | Always present | Notes |
| --- | --- | --- | --- |
| `commands` | array of `object` | no |  |
| `command` | `object` | no |  |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_UNKNOWN_COMMAND`](/docs/reference/error-codes#e_unknown_command)

A call over HTTP without credentials fails with `E_UNAUTHORIZED`, and too many calls with `E_RATE_LIMITED`. Both are in the [error codes](/docs/reference/error-codes).
