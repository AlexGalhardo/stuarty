<RefMain>

See the result. mode=frame returns one image of the timeline at time at; mode=sheet returns a grid of frames, each with its time printed (count evenly spaced between from and until, or explicit times). Costs image tokens: read project_get and lint first. frame needs at; sheet takes times, or from, to and count (not both).

## Behaviour

These are the annotations of the tool definition, the hints a client uses to decide whether to ask before a call. `view` is listed by `tools/list`.

| Property | Value |
| --- | --- |
| Read only | yes |
| Destructive | no |
| Idempotent | yes |
| Reaches outside the workspace | no |

## Input

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `project_id` | `string` | yes | pattern `^prj_[0-9a-hjkmnp-tv-z]{10}$` |
| `timeline_id` | `string` | no | pattern `^prj_[0-9a-hjkmnp-tv-z]{10}$` |
| `mode` | `frame`, `sheet` | no | default `"frame"` |
| `at` | `string` | no | Time: 12.5s, 375f or 00:00:12.500. Required in mode frame (the default). |
| `times` | array of `string` | no | at least 2 items; at most 16 items |
| `from` | `string` | no |  |
| `until` | `string` | no |  |
| `count` | `integer` | no | min 2; max 16; default `9` |
| `max_tokens` | `integer` | no | min 100; max 1568 |

## Output

A result has a text block, written for the model, and structured content with these members.

| Member | Type | Always present | Notes |
| --- | --- | --- | --- |
| `revision` | `integer` | yes |  |
| `width` | `integer` | yes |  |
| `height` | `integer` | yes |  |
| `image_tokens` | `integer` | yes |  |
| `cells` | array of `object` | no |  |
| `path` | `string` | no |  |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_INVALID_TIME`](/docs/reference/error-codes#e_invalid_time)

A call over HTTP without credentials fails with `E_UNAUTHORIZED`, and too many calls with `E_RATE_LIMITED`. Both are in the [error codes](/docs/reference/error-codes).

## Safety

- The only tool that returns an image, and an image costs tokens: read `project_get` and `lint` first, and lower `max_tokens` when a small image is enough.
- It renders through the export path: the frame is what export produces.
