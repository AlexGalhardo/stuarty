<RefMain>

Create an empty project (no tracks; add them with edit). Returns the project id and revision 0. preset is the frame size: 9:16 is 1080x1920 (default), 1:1, 16:9, 4:5.

## Behaviour

These are the annotations of the tool definition, the hints a client uses to decide whether to ask before a call. `project_create` is listed by `tools/list`.

| Property | Value |
| --- | --- |
| Read only | no |
| Destructive | no |
| Idempotent | no |
| Reaches outside the workspace | no |

## Input

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `name` | `string` | yes | min length 1; max length 120 |
| `preset` | `9:16`, `1:1`, `16:9`, `4:5` | no | default `"9:16"` |
| `fps` | `string` or `integer` | no | min 1; pattern `^[0-9]+(/1001)?$`; default `"30"` |
| `id` | `string` | no | pattern `^prj_[0-9a-hjkmnp-tv-z]{10}$` |
