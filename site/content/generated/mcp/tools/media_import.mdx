<RefMain>

Import local files into a project. paths: absolute paths of video, audio or image files. Starts an ingest job per file, waits up to wait_ms; use an asset in edit only when it is ready. Importing the same file twice returns the same asset. Returns asset and job ids; a refused file has an error in its entry.

## Behaviour

These are the annotations of the tool definition, the hints a client uses to decide whether to ask before a call. `media_import` is listed by `tools/list`.

| Property | Value |
| --- | --- |
| Read only | no |
| Destructive | no |
| Idempotent | yes |
| Reaches outside the workspace | no |

## Input

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `project_id` | `string` | yes | pattern `^prj_[0-9a-hjkmnp-tv-z]{10}$` |
| `timeline_id` | `string` | no | pattern `^prj_[0-9a-hjkmnp-tv-z]{10}$` |
| `paths` | array of `string` | yes | at least 1 items; at most 50 items |
| `asset_ids` | array of `string` | no | at most 50 items |
| `wait_ms` | `integer` | no | min 0; max 25000; default `10000` |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_LIMIT_EXCEEDED`](/docs/reference/error-codes#e_limit_exceeded)

A call over HTTP without credentials fails with `E_UNAUTHORIZED`, and too many calls with `E_RATE_LIMITED`. Both are in the [error codes](/docs/reference/error-codes).

## Safety

- `paths` are absolute paths of files on the machine of the server; a path that looks like a URL or a network share is refused.
- Text read from a file (its name, its metadata) is untrusted data, in double quotes or inside `untrusted_media_text` blocks.
