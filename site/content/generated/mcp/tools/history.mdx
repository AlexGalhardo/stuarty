<RefMain>

Read the change log (action=list, newest first, with actor; actor, cursor, limit only for list), or undo or redo your own latest step (action=undo or redo, one step per call). Undo skips a later change by another actor and reports it; an undo is itself a step.

## Behaviour

These are the annotations of the tool definition, the hints a client uses to decide whether to ask before a call. `history` is listed by `tools/list`.

| Property | Value |
| --- | --- |
| Read only | no |
| Destructive | no |
| Idempotent | no |
| Reaches outside the workspace | no |

## Input

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `project_id` | `string` | yes | pattern `^prj_[0-9a-hjkmnp-tv-z]{10}$` |
| `timeline_id` | `string` | no | pattern `^prj_[0-9a-hjkmnp-tv-z]{10}$` |
| `action` | `list`, `undo`, `redo` | no | default `"list"` |
| `actor` | `string` | no |  |
| `cursor` | `string` | no |  |
| `limit` | `integer` | no | min 1; max 100; default `20` |

## Output

A result has a text block, written for the model, and structured content with these members.

| Member | Type | Always present | Notes |
| --- | --- | --- | --- |
| `revision` | `integer` | yes |  |
| `kind` | `undo`, `redo` | no |  |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_NOTHING_TO_UNDO`](/docs/reference/error-codes#e_nothing_to_undo)
- [`E_NOTHING_TO_REDO`](/docs/reference/error-codes#e_nothing_to_redo)

A call over HTTP without credentials fails with `E_UNAUTHORIZED`, and too many calls with `E_RATE_LIMITED`. Both are in the [error codes](/docs/reference/error-codes).

## Safety

- `undo` and `redo` act on your own latest step only. A change another actor made after yours is skipped and reported.
- Undo is itself a step and can be redone.
