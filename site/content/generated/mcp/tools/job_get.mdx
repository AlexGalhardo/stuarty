<RefMain>

Get a job's state, progress and result (job_id). wait_ms waits for a final state (succeeded, failed, cancelled) for up to that many milliseconds. A succeeded export is verified; its result has the file path. Give project_id instead of job_id to list its queued, running and recent jobs.
