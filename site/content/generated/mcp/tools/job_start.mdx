Start long work. export renders a workspace file: args \{start?, end?, format?, at? (the png frame), preset?, codec?\}. export_batch runs args.items [\{preset, format, codec, start, end\}] in turn. transcribe: args \{asset_id, language?, model?\}. Poll job_get.

## Behaviour

These are the annotations of the tool definition, the hints a client uses to decide whether to ask before a call. `job_start` is listed by `tools/list`.

| Property | Value |
| --- | --- |
| Read only | no |
| Destructive | no |
| Idempotent | no |
| Reaches outside the workspace | no |

## Errors

- [`E_VALIDATION`](/docs/reference/error-codes#e_validation)
- [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found)
- [`E_LINT_BLOCKING`](/docs/reference/error-codes#e_lint_blocking)
- [`E_QUEUE_FULL`](/docs/reference/error-codes#e_queue_full)
- [`E_LIMIT_EXCEEDED`](/docs/reference/error-codes#e_limit_exceeded)

A call over HTTP without credentials fails with `E_UNAUTHORIZED`, and too many calls with `E_RATE_LIMITED`. Both are in the [error codes](/docs/reference/error-codes).

## Safety

- Lint errors block an export (`E_LINT_BLOCKING`): run `lint` first.
- An export writes one file in the workspace and sends nothing anywhere.
- `wait_ms` at most holds the call; poll `job_get` for the result.
