Stuarty publishes to Facebook through a developer app that you create and own (ADR-0035): no Stuarty account stands between you and Facebook, and the secret stays in your vault.

## Set up the developer app

Facebook publishes a **Reel** to a Page that you manage, through a Meta app that you create. It can be the same app as for Instagram.

1. Open the Meta for Developers console and create an app of the type **Business** (or use the one you made for Instagram).
2. Add **Facebook Login for Business** (or Facebook Login), and paste `<your Stuarty address>/social/callback` as a valid OAuth redirect address. The Connections page of Stuarty shows the exact value.
3. Keep the app in **development mode**, with yourself as an administrator.
4. In Stuarty, open **Connections**, choose **Connect**, pick Facebook, and paste the app id and the app secret. The secret goes into the vault.
5. Sign in, accept every permission, and **choose the Page** from the list Stuarty shows.

A Page video that is not a Reel (longer than 90 seconds, or not 9:16) is not offered: Stuarty refuses the post and names the limit, so nothing is sent. The Facebook pages state no largest file and no longest description, so Stuarty applies the stricter limits of Instagram to the text and a ceiling of 1 GiB to the file; the table below says which numbers are Facebook's and which are Stuarty's own.

## Permissions and hosts

The sign-in asks for these permissions and no others:

- `pages_show_list`
- `pages_read_engagement`
- `pages_manage_posts`

The only hosts Stuarty contacts for Facebook: `graph.facebook.com`, `rupload.facebook.com`. They are contacted only after you create the connection.

The official guide is [here](https://developers.facebook.com/docs/video-api/guides/reels-publishing) (read on 2026-11-19).

## Limits

These are the limits Stuarty checks a post to Facebook against before anything is sent (`publish:validate`). A post that breaks one is refused with the limit named, and nothing leaves your machine.

| Limit | Value |
| --- | --- |
| Title | at most 2200 characters |
| Caption | at most 2200 characters |
| Hashtags | at most 30 |
| Description | at most 8800 bytes |
| Tags | at most 2200 characters in all |
| Video file | at most 1.1 GB |
| Video formats | mp4 |
| Video codecs | h264, hevc |
| Audio codecs | aac |
| Shortest video | 3 s |
| Longest video | 90 s |
| Frame rate | 24 to 60 fps |
| Smallest picture | 540 x 960 pixels |
| Export size of the preset | 1080 x 1920 |
| Thumbnail | not sent |
| Visibility | public |
| Posts through the API | 30 in a moving 24 hours |

### Where the numbers come from

- [Facebook: the page for the post](https://developers.facebook.com/docs/video-api/guides/reels-publishing), read on 2026-11-19.
- [The page for the video](https://developers.facebook.com/docs/video-api/guides/reels-publishing/), read on 2026-11-19: .mp4, H.264 or H.265, 24 to 60 fps, 9x16, 1080x1920 recommended and 540x960 minimum, 3 to 90 s, AAC-LC 48 kHz stereo 128 kbit/s or more.

Facebook publishes only after you approve the post.
