Image documents: layers, text, shapes, templates with slots, export to PNG, JPEG or WebP.

## How to reach it

MCP tools: `edit`, `command_help`, `history`, `image`. Tools that take `domain=image`: `edit`, `command_help`, `history`.

CLI: `stuarty image` lists the commands of the domain and `stuarty image <verb>` runs one; the full names stay valid.

- `image:create`: create an image document, blank or from a template
- `image:list`: list the image documents and templates
- `image:show`: describe an image document: its layers, its findings and its revision
- `image:edit`: apply a batch of image operations (stuarty command:help --domain image lists them)
- `image:undo`: undo the last step of the caller on an image
- `image:redo`: redo the last undone step of the caller on an image
- `image:export`: export an image document to a PNG, JPEG or WebP file
- `image:import`: bring an image file into a new image document, or into an existing one as a layer

## Operations

These 26 operations go in the `operations` of `edit` with `domain=image`, grouped by namespace; `command_help domain=image` lists them with their summaries and `command_help name=<operation> domain=image` gives the arguments of one.

- `canvas`: resize
- `image`: create
- `layer`: add_fill, add_image, add_shape, add_text, adjust, align, blend, crop, duplicate, filter_add, filter_move, filter_remove, filter_set, fit, group, mask_clear, mask_set, move, remove, set, set_shape, set_text, transform, ungroup
