Files of the workspace: media import and inspection, the asset library (origin, tags, reuse), fonts.

## How to reach it

MCP tools: `command_help`, `media_import`, `media_inspect`, `font_import`. Tools that take `domain=asset`: `command_help`.

CLI: `stuarty asset` lists the commands of the domain and `stuarty asset <verb>` runs one; the full names stay valid.

- `media:import`: import media files into a project
- `media:inspect`: show what is known about an asset
- `media:list`: list the assets of a project
- `media:trash`: move an asset to the trash
- `media:restore`: restore a trashed asset
- `fonts`: list the bundled font families
- `font:import`: add a TrueType or OpenType font file to the font store
- `asset:list`: list the files of the library, with origin, tags and reuse
- `asset:show`: show a file of the library: its origin, its tags and the projects that use it
- `asset:uses`: list the projects that use a file of the library
- `asset:set`: set the description, the rights note and the reuse mark of a file of the library
- `asset:tag`: add and remove the tags of a file of the library
- `asset:rename`: rename a file of the library; the stored file keeps its hash

## Operations

No edit operations yet. The domain is reached through the tools and commands above; operations that a later epic registers in it appear here, and `command_help domain=asset` lists them.
