The installation: command help, connections, brand kit, health, audit.

## How to reach it

MCP tools: `command_help`, `connection`. Tools that take `domain=workspace`: `command_help`.

CLI: `stuarty workspace` lists the commands of the domain and `stuarty workspace <verb>` runs one; the full names stay valid.

- `version`: print the version of this binary
- `mcp`: serve the MCP tools on standard input and output
- `command:help`: list the editing commands and the domains, or describe one command
- `agent:docs`: print or write the material for agents: the skill, the AGENTS.md snippet, the MCP instructions
- `doctor`: check the installation and the workspace
- `audit`: list the audit table
- `tools:install`: download a helper such as the transcription program
- `token:rotate`: replace the local token; clients that hold the old one must be set up again
- `brand:show`: show the brand kit: logo, colours and fonts
- `brand:set`: replace the brand kit
- `connection:list`: list the destinations Stuarty may reach
- `connection:show`: show one connection: destinations, what it accepts and its last use
- `connection:add`: connect a destination; the secret is read from standard input or a file, never from an argument
- `connection:remove`: remove a connection and its credential
- `connection:test`: make one request through a connection and show how the destination answered
- `agent:profiles`: list the agents the chat may host, with their full command, and the known agents found on this machine
- `chat:sessions`: list the chat sessions of a project, newest first
- `chat:session`: show one chat session: its agent, its state and how many events it holds
- `chat:transcript`: read the transcript of a chat session as events, or the whole of it as Markdown

## Operations

No edit operations yet. The domain is reached through the tools and commands above; operations that a later epic registers in it appear here, and `command_help domain=workspace` lists them.
