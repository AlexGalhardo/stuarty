## Errors of the service

Raised around the commands: sign-in, imports, exports, jobs and limits. They appear in the results of the calls that raise them. A code that is not in the status table of the service answers with HTTP 500, which is the status of the failures of a job.

| Code | HTTP | Retryable | Meaning |
| --- | --- | --- | --- |
| `E_APPROVAL_EXPIRED` | 409 | no | in the error of a job whose approval request expired before a person answered (SDD-015 §3) |
| `E_APPROVAL_NOT_FOUND` | 404 | no | the approval request or the approval rule does not exist (SDD-015 §8) |
| `E_ASSET_NOT_READY` | 409 | yes | the asset is still ingesting |
| `E_CANCELLED` | 500 | no | the job was cancelled |
| `E_CLIENT_CLOSED` | 499 | no | the caller closed the request (or its deadline passed) before the answer; status 499, logged below error level, never a server fault |
| `E_CONNECTION_DESTINATION` | 403 | no | a request through a connection is for a host or a scheme it does not allow (SDD-014 §6) |
| `E_CONNECTION_NOT_FOUND` | 404 | no | the connection does not exist or was removed (SDD-014 §7) |
| `E_COST_CEILING` | 422 | no | an estimate is over a cost ceiling; `details` hold `scope`, `reason`, `limit_micros`, `spent_micros`, `estimate_micros`, `currency`; nothing was spent (SDD-015 §6) |
| `E_EXPORT_FAILED` | 500 | no | the export process failed; `details.reason` |
| `E_FFMPEG_MISSING` | 503 | no | no usable FFmpeg was found |
| `E_FILE_NOT_FOUND` | 404 | no | the path does not exist or cannot be read |
| `E_FORBIDDEN` | 403 | no | the key lacks the scope or is limited to another project |
| `E_INGEST_FAILED` | 500 | no | ingest failed; `details.reason` |
| `E_LIMIT_EXCEEDED` | 422 | no | a configured ceiling (file size, duration, resolution) is exceeded |
| `E_LINT_BLOCKING` | 422 | no | an export was refused because the lint has errors; `details.findings` |
| `E_METHOD_NOT_ALLOWED` | 405 | no | HTTP only: the route does not answer that method; `OPTIONS` is always refused (no CORS, SDD-007 §3.6) |
| `E_NO_ENCODER` | 503 | no | no encoder works on this machine for the codec the export needs (H.264, or the `details.codec` that was asked for: `hevc` or `av1`, SDD-004 section 8.3); `details.reason` `codec_unavailable` and `details.candidates` |
| `E_NOTHING_TO_REDO` | 409 | no | the actor has no step to undo or redo |
| `E_NOTHING_TO_UNDO` | 409 | no | the actor has no step to undo or redo |
| `E_PATH_NOT_ALLOWED` | 403 | no | a path is outside the allowed import roots or is not a regular file |
| `E_PAYLOAD_TOO_LARGE` | 413 | no | a request or batch is too large |
| `E_PRIVILEGED_SESSION` | 403 | no | the operation is for a person in a privileged browser session; the caller is the local token, a key or an agent surface (SDD-015 §4) |
| `E_QUEUE_FULL` | 429 | yes | a concurrency limit is reached; `details.limit` names it (`exports`, `exports_per_key`, `ingests`, `transcribes`, `streams`, `frames`) with `value` and `ceiling`, and `details.running` lists the jobs of a job queue |
| `E_RATE_LIMITED` | 429 | yes | the caller sent too many requests; the answer carries `Retry-After`, and `details` has `retry_after`, `limit`, `value` and `ceiling` |
| `E_TRANSCRIBE_FAILED` | 500 | no | a transcription ran and failed (no output, provider error, no word timings); `details.reason` |
| `E_TRANSCRIBE_UNAVAILABLE` | 503 | no | no transcription provider is installed or configured; `details` names what is missing, its download size, the install command and the `tool` and `model` it installs |
| `E_UNAUTHORIZED` | 401 | no | missing or invalid token, key or session |
| `E_UNSUPPORTED_MEDIA` | 422 | no | the file is not media FFmpeg can decode, or has no usable stream |
| `E_VAULT_LOCKED` | 503 | no | the vault cannot be opened: master key missing, wrong or not storable; `details.reason` (SDD-014 §4) |
| `E_VERIFY_FAILED` | 500 | no | the exported file did not pass verification; `details.checks` |
| `E_WORKSPACE_LOCKED` | 503 | yes | another process owns the workspace and cannot be reached |
