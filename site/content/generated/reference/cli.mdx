The CLI is a thin adapter over the same service as the editor, the MCP server and the HTTP API. Add `--json` to any command for one JSON document on standard output.

## Global flags

| Flag | Type | Default | Meaning |
| --- | --- | --- | --- |
| `--json` | boolean | `false` | print one JSON document |
| `--project` | string |  | project id (default $STUARTY_PROJECT) |
| `--workspace` | string |  | workspace directory (default $STUARTY_HOME, else ~/.stuarty) |
| `--actor` | string | `cli` | label of the actor local:&lt;label&gt; |
| `--key-file` | string |  | file holding an API key for a remote server |
| `--dry-run` | boolean | `false` | validate and report, change nothing |
| `--wait` | boolean | `true` | block until the job is final (--no-wait to return at once) |
| `--timeout` | duration | `10m` | longest --wait |

## Exit codes

| Code | Meaning |
| --- | --- |
| 0 | success |
| 1 | a failure that retrying will not fix, a failed file of media:import, a failed job, or lint --strict with an error finding |
| 2 | a retryable error (E_REVISION_CONFLICT, E_WORKSPACE_LOCKED, E_QUEUE_FULL, E_RATE_LIMITED, E_ASSET_NOT_READY) or a --wait that timed out |

## `media:import`

Import media files into a project

```text
stuarty media:import <path>... --project <id> [--asset-id ast_...] [--wait] [--timeout d]
stuarty media:import --hash sha256:... --project <id>   (a file the library already holds: no copy)
origin and reuse: [--origin-kind k] [--origin-source s] [--provider p] [--model m] [--prompt t] [--rights-note t] [--engine e] [--engine-version v] [--render-key k] [--tag t] [--reusable] [--description t]
formats: MP4, MOV, MKV, WebM, AVI, MP3, WAV, FLAC, OGG, PNG, JPEG, WebP, GIF and .cube; not SVG
```

| Flag | Type | Default | Meaning |
| --- | --- | --- | --- |
| `--asset-id` | string, repeatable |  | id to give the asset, once per path, in order |
| `--hash` | string, repeatable |  | the hash of a file of the library to use in the project, in place of a path |
| `--origin-kind` | string |  | imported (default), generated, fetched_by_agent or rendered_externally |
| `--origin-source` | string |  | a path, a URL or a tool name, as plain text (required for fetched_by_agent and rendered_externally) |
| `--provider` | string |  | the provider that generated the files (required for generated) |
| `--model` | string |  | the model that generated the files (required for generated) |
| `--prompt` | string |  | the prompt that generated the files |
| `--cost-micros` | integer |  | what the files cost, in millionths of a US dollar |
| `--engine` | string |  | the motion engine that rendered the files (rendered_externally) |
| `--engine-version` | string |  | the version of that engine (rendered_externally) |
| `--render-key` | string |  | a stable name for the animation, the same each time it is rendered again (rendered_externally) |
| `--rights-note` | string |  | your own record of the licence or the permission (required for fetched_by_agent) |
| `--tag` | string, repeatable |  | a tag for the files; repeat it or give a comma list |
| `--reusable` | boolean |  | mark the files to be offered again |
| `--description` | string |  | what the files are, in your words |

Global flags: `--json`, `--workspace`, `--actor`, `--key-file`, `--project`, `--wait`, `--timeout`.

## `view`

Render a frame or a contact sheet of a project, or measure its sound

```text
stuarty view --project <id> [--mode frame|sheet|audio] [--at t] [--times t1,t2,...]
    [--from t --until t --count n] [--cols n] [--max-tokens n] [--width px] [--item id]
```

| Flag | Type | Default | Meaning |
| --- | --- | --- | --- |
| `--mode` | string | `frame` | frame (one image at --at), sheet (a grid) or audio (the loudness, true peak and noise floor with and without the audio processors) |
| `--item` | string |  | audio: measure this clip or audio item alone |
| `--at` | string |  | frame: the time to show |
| `--times` | string |  | sheet: 2 to 16 times, comma separated |
| `--from` | string |  | sheet: first time (default 0s); audio: start of the range |
| `--until` | string |  | sheet: last time, included (default the last frame); audio: end of the range, excluded |
| `--count` | integer | `9` | sheet: frames evenly spaced from --from to --until |
| `--cols` | integer |  | sheet: columns (default ceil(sqrt(count))) |
| `--max-tokens` | integer |  | image token budget (default 800, a sheet 1,500; at most 1,568) |
| `--width` | integer |  | image width in pixels, even; exclusive with --max-tokens |

Global flags: `--json`, `--workspace`, `--actor`, `--key-file`, `--project`.

Example:

```bash
stuarty view --project prj_7k2m9x4q1b --at 1s --json
```
