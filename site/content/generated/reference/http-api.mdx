The API is served at `/api/v1` by `vukem-video serve`, on `127.0.0.1:7878`. In local mode every route needs the bearer token from `<workspace>/token`; in [network mode](/docs/self-hosting/network-mode) a request carries a session cookie or an [API key](/docs/self-hosting/api-keys) instead, and the key scopes decide what it may do. Errors are `application/problem+json` with `code`, `message`, `hint` and `retryable`. The OpenAPI document itself is at `/openapi.json` while the server runs.
