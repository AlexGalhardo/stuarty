The API is served at `/api/v1` by `vukem-video serve`, on `127.0.0.1:7878`. Every route needs the bearer token from `<workspace>/token`. Errors are `application/problem+json` with `code`, `message`, `hint` and `retryable`. The OpenAPI document itself is at `/openapi.json` while the server runs.
