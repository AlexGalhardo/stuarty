Adds a visual or audio track. It goes on top by default; position bottom, above or below another track places it elsewhere. The first track in the order is the top layer.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `above` | `string` | Place the track directly over this track. | Place the track directly over this track. |
| `below` | `string` | Place the track directly under this track. | Place the track directly under this track. |
| `id` | `string` |  |  |
| `kind` | `visual`, `audio` |  |  |
| `name` | `string` |  |  |
| `position` | `top`, `bottom` | top (default) or bottom. | top (default) or bottom. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "track.add",
  "args": {
    "id": "trk_a1b2c3d4e5",
    "kind": "visual",
    "name": "Captions"
  }
}
```
