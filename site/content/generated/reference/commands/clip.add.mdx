Adds a clip. The default duration is the rest of the asset from source_in, or 5 seconds for an image. The reserved asset ast_placeholder creates a template slot holder and needs an explicit duration.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `asset_id` | `string` | A video or image asset, or ast_placeholder in a template. | A video or image asset, or ast_placeholder in a template. |
| `duration` | `string` | A length; default the rest of the asset, or 5s for an image. | A length; default the rest of the asset, or 5s for an image. |
| `fit` | `cover`, `contain`, `none` |  |  |
| `id` | `string` |  |  |
| `source_in` | `string` | Offset into the asset; default 0s; omit for an image. | Offset into the asset; default 0s; omit for an image. |
| `start` | `string` | Absolute position. | Absolute position. |
| `track_id` | `string` | A visual track. | A visual track. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "clip.add",
  "args": {
    "asset_id": "ast_3c5v8n2w6d",
    "duration": "5s",
    "id": "itm_m1n2p3q4r5",
    "source_in": "2s",
    "start": "0s",
    "track_id": "trk_f6g7h8j9k0"
  }
}
```
