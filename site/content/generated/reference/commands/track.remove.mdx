Removes the track. A track with items is refused with E_NOT_EMPTY unless with_items is true, in which case its items are removed too.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `track_id` | `string` |  |  |
| `with_items` | `boolean` | Remove the items of the track too. | Remove the items of the track too. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "track.remove",
  "args": {
    "track_id": "trk_f6g7h8j9k0",
    "with_items": true
  }
}
```

## Errors

[`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found), [`E_NOT_EMPTY`](/docs/reference/error-codes#e_not_empty)
