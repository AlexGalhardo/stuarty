{/* Generated by site/scripts/generate-reference.ts. Do not edit. */}

enabled false keeps the item, its place and its settings, and makes the preview, the export and the audio mix ignore it; true turns it back on. Works on every item type.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `enabled` | `boolean` | yes | false turns the item off, true turns it on. |
| `item_id` | `string` | yes | Any item. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "item.set_enabled",
  "args": {
    "enabled": false,
    "item_id": "itm_m1n2p3q4r5"
  }
}
```
