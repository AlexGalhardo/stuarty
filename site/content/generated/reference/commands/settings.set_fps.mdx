Rescales every time quantity q of the project to round(q * new / old), then repairs what rounding can break: durations that became 0, the source range, overlaps, keyframes, caption words, fades and transitions. effective.adjusted lists every item changed by a repair. A rate is 1 to 120 fps with a denominator of 1 or 1001.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `fps` | `string` or `object` | yes | "30", "30000/1001" or \{"num": 30000, "den": 1001\}; den is 1 or 1001, 1 to 120 fps. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "settings.set_fps",
  "args": {
    "fps": "24"
  }
}
```
