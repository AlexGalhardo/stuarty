title: "caption.merge"
description: "Joins two captions of one track into one that spans both."
---

{/* Generated by site/scripts/generate-reference.ts. Do not edit. */}

The caption that starts first keeps its identifier, style and position and takes the words of the other; the other is removed. Captions with keyframes cannot be merged.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_ids` | array of `string` | Exactly two distinct captions of one track, in any order. | Exactly two distinct captions of one track, in any order. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "caption.merge",
  "args": {
    "item_ids": [
      "itm_s6t7v8w9x0",
      "itm_c3d4e5f6g7"
    ]
  }
}
```
