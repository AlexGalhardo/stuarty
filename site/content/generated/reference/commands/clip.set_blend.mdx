Sets one blend mode of the fixed list (normal, multiply, screen, overlay, add). normal is the default and clears the stored one. Works on clip, text, caption and shape items.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | A visual item. |
| `mode` | `normal`, `multiply`, `screen`, `overlay`, `add` | yes | normal, multiply, screen, overlay or add. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "clip.set_blend",
  "args": {
    "item_id": "itm_m1n2p3q4r5",
    "mode": "screen"
  }
}
```
