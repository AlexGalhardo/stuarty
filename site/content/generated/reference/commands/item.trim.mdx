Moves an edge to an absolute position and keeps the source range, the keyframes and the caption words consistent. The end edge is exclusive: it is the first frame after the item.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `edge` | `start`, `end` |  |  |
| `item_id` | `string` |  |  |
| `to` | `string` | Absolute position of the edge; the end is exclusive. | Absolute position of the edge; the end is exclusive. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "item.trim",
  "args": {
    "edge": "start",
    "item_id": "itm_m1n2p3q4r5",
    "to": "97f"
  }
}
```
