Removes the marker at a frame; all removes every marker of the timeline.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `all` | `boolean` | no | true removes every marker of the timeline, instead of at. |
| `at` | `string` | no | The position of the marker to remove. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "marker.remove",
  "args": {
    "at": "12.5s"
  }
}
```
