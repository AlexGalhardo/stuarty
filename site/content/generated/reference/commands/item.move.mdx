Sets the start of the item, its track, or both; at least one is required. Keyframes, words, transitions and fades are relative to the item and travel with it.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_id` | `string` |  |  |
| `start` | `string` | The new absolute position of the first frame. | The new absolute position of the first frame. |
| `track_id` | `string` | A track that accepts the item type. | A track that accepts the item type. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "item.move",
  "args": {
    "item_id": "itm_m1n2p3q4r5",
    "start": "5s"
  }
}
```
