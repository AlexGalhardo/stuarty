Removes the keyframe at the absolute position. The last keyframe of a property writes its value into the static field.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `at` | `string` | yes | Absolute position of the keyframe. |
| `item_id` | `string` | yes |  |
| `property` | `x`, `y`, `scale`, `rotation`, `opacity`, `volume` | yes |  |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "keyframe.remove",
  "args": {
    "at": "2s",
    "item_id": "itm_s6t7v8w9x0",
    "property": "scale"
  }
}
```
