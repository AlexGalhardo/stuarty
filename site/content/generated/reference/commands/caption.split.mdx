The right part starts with the word at before_word. Style and the linked clip are copied to it; transition_out moves to it. The cut falls at the start of that word, so the parts cover the original range.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `before_word` | `integer` | yes | Index of the first word of the right part. min 1 |
| `item_id` | `string` | yes | A caption. |
| `new_id` | `string` | no | The id of the right part. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "caption.split",
  "args": {
    "before_word": 2,
    "item_id": "itm_s6t7v8w9x0",
    "new_id": "itm_c3d4e5f6g7"
  }
}
```
