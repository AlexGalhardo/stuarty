Replaces the text, merges a partial style into the stored one (null removes a key), or empties the style first with reset_style. At least one of text, style and reset_style is required.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_id` | `string` | A text item. | A text item. |
| `reset_style` | `boolean` | Empty the stored style before applying style. | Empty the stored style before applying style. |
| `style` | `object` | A partial TextStyle, merged; null removes a key. | A partial TextStyle, merged; null removes a key. |
| `text` | `string` |  |  |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "text.set",
  "args": {
    "item_id": "itm_s6t7v8w9x0",
    "style": {
      "color": "#FFE600"
    },
    "text": "Hello world"
  }
}
```
