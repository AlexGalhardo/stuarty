Adds an audio item on an audio track with the same asset, start, duration, source range, speed, curve, reverse, volume, fades, noise reduction and volume keyframes as the clip, links the two, and sets audio_muted on the clip so the sound is not heard twice.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | `string` | no | The id of the new audio item. |
| `item_id` | `string` | yes | A clip of a video asset with audio. |
| `track_id` | `string` | yes | An audio track with room for the item. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "item.extract_audio",
  "args": {
    "item_id": "itm_m1n2p3q4r5",
    "track_id": "trk_m1n2p3q4r5"
  }
}
```
