Adds an audio item. The default duration is the rest of the asset from source_in. The reserved asset ast_placeholder creates a template slot holder and needs an explicit duration.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `asset_id` | `string` | yes | An audio asset, a video asset with audio, or ast_placeholder in a template. |
| `duration` | `string` | no | A length; default the rest of the asset. |
| `id` | `string` | no |  |
| `source_in` | `string` | no | Offset into the asset; default 0s. |
| `start` | `string` | yes | Absolute position. |
| `track_id` | `string` | yes | An audio track. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "audio.add",
  "args": {
    "asset_id": "ast_4h6j8k2m3n",
    "id": "itm_s6t7v8w9x0",
    "start": "1s",
    "track_id": "trk_m1n2p3q4r5"
  }
}
```
