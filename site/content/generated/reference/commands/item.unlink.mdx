Takes each listed item out of its link group. A group left with one item is dissolved, so the item that remains is unlinked too (listed in effective.also_unlinked).

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_ids` | array of `string` | yes | The items to take out of their link group. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "item.unlink",
  "args": {
    "item_ids": [
      "itm_c3d4e5f6g7"
    ]
  }
}
```

## Errors

[`E_VALIDATION`](/docs/reference/error-codes#e_validation), [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found), [`E_INVALID_STATE`](/docs/reference/error-codes#e_invalid_state)
