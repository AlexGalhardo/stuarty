Sets a mask in the item's own frame: x, y, width and height are fractions of the item (0 to 1, x plus width and y plus height at most 1), feather is the soft edge in pixels (0 to 200, default 0) and invert keeps the outside instead. Replaces the current mask. Works on clip, text, caption and shape items. mask null removes it.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | A visual item. |
| `mask` | `object or null` | yes | The mask, or null to remove it. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "clip.set_mask",
  "args": {
    "item_id": "itm_m1n2p3q4r5",
    "mask": {
      "feather": 12,
      "height": 0.8,
      "shape": "ellipse",
      "width": 0.8,
      "x": 0.1,
      "y": 0.1
    }
  }
}
```
