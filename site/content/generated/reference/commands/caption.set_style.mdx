title: "caption.set_style"
description: "Sets or clears the style override of one caption."
---

{/* Generated by site/scripts/generate-reference.ts. Do not edit. */}

The given object replaces the whole override and is stored as given. null or \{\} clears it. The caption style of the track is not touched.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | A caption. |
| `style` | `object or null` | yes | A partial CaptionStyle replacing the override, or null or \{\} to clear it. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "caption.set_style",
  "args": {
    "item_id": "itm_s6t7v8w9x0",
    "style": {
      "highlight": "word",
      "size": 80
    }
  }
}
```
