Sets the display name of the item; an empty name clears it.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_id` | `string` | The item to label. | The item to label. |
| `name` | `string` | The label, 0 to 120 characters; empty clears it. | The label, 0 to 120 characters; empty clears it. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "item.rename",
  "args": {
    "item_id": "itm_m1n2p3q4r5",
    "name": "Intro shot"
  }
}
```
