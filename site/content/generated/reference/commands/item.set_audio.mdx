{/* Generated by site/scripts/generate-reference.ts. Do not edit. */}

Sets the given values. Volume 1, fades of 0, audio_muted false and denoise 0 clear the stored value. audio_muted applies to clip items only. denoise is the noise reduction strength, 0 to 1. The two fades together cannot be longer than the item.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `audio_muted` | `boolean` | no | Drop the audio of a clip. |
| `denoise` | `number` | no | Noise reduction strength, 0 (off) to 1. min 0; max 1 |
| `fade_in` | `string` | no | Fade-in length; 0s removes it. |
| `fade_out` | `string` | no | Fade-out length; 0s removes it. |
| `item_id` | `string` | yes | A clip or audio item. |
| `volume` | `number` | no | Linear gain, 0 to 4. min 0; max 4 |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "item.set_audio",
  "args": {
    "fade_in": "1s",
    "fade_out": "0.5s",
    "item_id": "itm_m1n2p3q4r5",
    "volume": 0.8
  }
}
```
