Names a font that is already stored by hash in the workspace as a family of the project, so that styles can use it. The family name must not be a bundled family. Adding to an existing family adds the weights and replaces the file of a weight it already has. The command never reads or stores a file; the service refuses a hash that the workspace does not hold.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `family` | `string` | yes | 1 to 60 characters: letters, digits, space, dot, hyphen, underscore; not a bundled family. |
| `files` | array of `object` | yes | One file per weight, 1 to 9; a weight appears once. at least 1 items; at most 9 items |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "font.add",
  "args": {
    "family": "Brand Sans",
    "files": [
      {
        "hash": "sha256:abababababababababababababababababababababababababababababababab",
        "weight": 400
      },
      {
        "hash": "sha256:cdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcd",
        "weight": 700
      }
    ]
  }
}
```
