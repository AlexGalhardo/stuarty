The value at the first frame of the item becomes the static value. Without property, every animated property is cleared.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_id` | `string` | yes |  |
| `property` | `x`, `y`, `scale`, `rotation`, `opacity`, `volume` | no | One property; default every animated property. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "keyframe.clear",
  "args": {
    "item_id": "itm_s6t7v8w9x0",
    "property": "opacity"
  }
}
```
