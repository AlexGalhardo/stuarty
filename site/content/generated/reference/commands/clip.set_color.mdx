{/* Generated by site/scripts/generate-reference.ts. Do not edit. */}

Sets the given adjustments, rounded to 3 decimals; a value equal to the default (brightness 0, contrast 1, saturation 1, temperature 0, tint 0, hue 0) clears the stored one. Positive temperature is warmer, positive tint is more magenta, hue rotates the colours in degrees.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `brightness` | `number` | no | -1 to 1; default 0. min -1; max 1 |
| `contrast` | `number` | no | 0 to 2; default 1. min 0; max 2 |
| `hue` | `number` | no | -180 to 180 degrees; default 0. min -180; max 180 |
| `item_id` | `string` | yes | A clip. |
| `saturation` | `number` | no | 0 to 2; default 1. min 0; max 2 |
| `temperature` | `number` | no | -1 (cooler) to 1 (warmer); default 0. min -1; max 1 |
| `tint` | `number` | no | -1 (greener) to 1 (more magenta); default 0. min -1; max 1 |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "clip.set_color",
  "args": {
    "brightness": 0.1,
    "item_id": "itm_m1n2p3q4r5",
    "temperature": 0.3
  }
}
```
