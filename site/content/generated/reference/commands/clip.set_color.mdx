Sets the given adjustments, rounded to 3 decimals; a value equal to the default (brightness 0, contrast 1, saturation 1) clears the stored one.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `brightness` | `number` | -1 to 1; default 0. min -1; max 1 | -1 to 1; default 0. min -1; max 1 |
| `contrast` | `number` | 0 to 2; default 1. min 0; max 2 | 0 to 2; default 1. min 0; max 2 |
| `item_id` | `string` | A clip. | A clip. |
| `saturation` | `number` | 0 to 2; default 1. min 0; max 2 | 0 to 2; default 1. min 0; max 2 |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "clip.set_color",
  "args": {
    "brightness": 0.1,
    "item_id": "itm_m1n2p3q4r5",
    "saturation": 1.2
  }
}
```
