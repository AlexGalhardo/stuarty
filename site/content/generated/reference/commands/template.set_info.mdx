Sets the description and adds, replaces or (with null) removes named colours. A colour that a style, a shape or the background still refers to as "$name" cannot be removed. A document that has no template gets one.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `colors` | `object` | no | Name to #RRGGBB or #RRGGBBAA; null removes the name. |
| `description` | `string` | no | 0 to 500 characters. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "template.set_info",
  "args": {
    "colors": {
      "brand": "#ff3366",
      "old": null
    },
    "description": "Product teaser"
  }
}
```
