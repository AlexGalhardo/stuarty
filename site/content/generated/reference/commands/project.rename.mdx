Sets the name of the project. The name is stored exactly as given, without trimming.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | `string` | The new name, 1 to 120 characters. | The new name, 1 to 120 characters. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "project.rename",
  "args": {
    "name": "Launch teaser v2"
  }
}
```
