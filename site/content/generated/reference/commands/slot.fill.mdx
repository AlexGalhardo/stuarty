{/* Generated by site/scripts/generate-reference.ts. Do not edit. */}

Give exactly one of asset_id (media slot), text (text slot) or words (caption slot). A media slot with duration policy fit keeps its duration and needs an asset long enough; with stretch_timeline it takes the rest of the asset and the later items of every track follow.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `asset_id` | `string` | For a media slot. | For a media slot. |
| `name` | `string` | The slot name. | The slot name. |
| `source_in` | `string` | With asset_id only. Default "0s". | With asset_id only. Default "0s". |
| `text` | `string` | For a text slot. | For a text slot. |
| `words` | array of `object` | For a caption slot: words with times relative to the caption, as lengths. | For a caption slot: words with times relative to the caption, as lengths. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "slot.fill",
  "args": {
    "asset_id": "ast_4h6j8k2m3n",
    "name": "hero",
    "source_in": "1s"
  }
}
```
