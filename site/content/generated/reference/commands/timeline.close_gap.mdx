Moves the items after the gap earlier by the length of the gap: those of the track (ripple track, the default) or those of every track (ripple all).

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `at` | `string` | Absolute frame inside the gap. | Absolute frame inside the gap. |
| `ripple` | `track`, `all` | track (default) or all: all moves later items of every track. | track (default) or all: all moves later items of every track. |
| `track_id` | `string` | The track with the gap. | The track with the gap. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "timeline.close_gap",
  "args": {
    "at": "70f",
    "track_id": "trk_f6g7h8j9k0"
  }
}
```
