Replaces the text of the word at index; timing is untouched. An empty text removes the word and leaves a gap. The only word of a caption cannot be removed.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `index` | `integer` | yes | 0-based index of the word. min 0 |
| `item_id` | `string` | yes | A caption. |
| `text` | `string` | yes | The new text, 0 to 80 characters, no whitespace; empty removes. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "caption.edit_word",
  "args": {
    "index": 3,
    "item_id": "itm_s6t7v8w9x0",
    "text": "editor"
  }
}
```
