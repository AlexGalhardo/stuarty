Places a marker at each beat of the visible part of the item, or at every nth beat, so that cuts and transitions can be aligned to the music. Beats are frames of the asset and come from the beat grid of the asset, supplied by the service in resolved; the command never starts a job. Markers have no effect on the picture or the sound.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `every` | `integer` | no | Mark every nth beat of the visible part, from the first; default 1. min 1; max 64 |
| `item_id` | `string` | yes | An audio item of an audio asset, or of a video asset with audio. |
| `label` | `string` | no | Label of every marker, up to 60 characters; default none. |
| `replace` | `boolean` | no | true (default) replaces the item's markers; false keeps them and adds the beats. |
| `resolved` | `object` | no | Filled by the service from the beat grid of the asset; never sent by a caller. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "audio.mark_beats",
  "args": {
    "every": 2,
    "item_id": "itm_s6t7v8w9x0",
    "label": "beat"
  }
}
```
