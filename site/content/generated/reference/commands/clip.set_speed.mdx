Sets either speed, from 0.25x to 4x, or curve, 2 to 8 points \{t, speed\} with t the fraction of the item from 0 to 1 (first 0, last 1) and a linear ramp between points; a speed clears the curve. Rescales the duration, the fades, the transitions and the keyframes by the ratio of the old to the new mean speed. With ripple track the later items of the track follow the change in length. Captions linked to the clip are listed, not changed. reverse true plays the same source range backwards (false restores it), alone or with a speed or a curve.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `curve` | array of `object` | no | Speed ramp: 2 to 8 points, linear between them, first t 0 and last t 1. Not with speed. |
| `item_id` | `string` | yes | A clip of a video asset, or an audio item. |
| `reverse` | `boolean` | no | true plays the source range backwards; false plays it forwards. |
| `ripple` | `none`, `track` | no | none (default) or track: shift the later items of the track. |
| `speed` | `string` or `object` | no | "1.5x" (up to 3 decimals) or \{"num": 3, "den": 2\}; 1/4 to 4. Not with curve. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "clip.set_speed",
  "args": {
    "curve": [
      {
        "speed": "1x",
        "t": 0
      },
      {
        "speed": "3x",
        "t": 0.5
      },
      {
        "speed": "1x",
        "t": 1
      }
    ],
    "item_id": "itm_m1n2p3q4r5"
  }
}
```
