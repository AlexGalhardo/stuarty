Sets one filter of the fixed list (none, grayscale, sepia, invert, warm, cool) and its amount, 0 (the original) to 1 (the full filter), rounded to 3 decimals; a value equal to the default (none, 1) clears the stored one.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `amount` | `number` | no | 0 to 1; default 1. min 0; max 1 |
| `filter` | `none`, `grayscale`, `sepia`, `invert`, `warm`, `cool` | no | none (default), grayscale, sepia, invert, warm or cool. |
| `item_id` | `string` | yes | A clip, text, caption or shape item. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "clip.set_filter",
  "args": {
    "amount": 0.6,
    "filter": "sepia",
    "item_id": "itm_m1n2p3q4r5"
  }
}
```
