Replaces the whole list of effects, applied in order; an empty list removes them. Each kind appears at most once and takes only its own parameters (omitted ones get the defaults): motion_blur amount 0.5 and angle 0; glow amount 0.5, radius 12 and threshold 0.6; vignette amount 0.5 and softness 0.5; grain amount 0.3, size 1 and seed 0; rgb_split amount 0.3 and angle 0; shake amount 0.3, speed 8 and seed 0.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `effects` | array of `object` | yes | The effects in order, up to 6, each kind once; [] removes them all. |
| `item_id` | `string` | yes | A clip. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "clip.set_effects",
  "args": {
    "effects": [
      {
        "amount": 0.6,
        "kind": "vignette"
      },
      {
        "kind": "grain"
      }
    ],
    "item_id": "itm_m1n2p3q4r5"
  }
}
```
