Makes a clip, audio, text or caption item a slot named name; the slot kind follows from the item type (clip and audio give media). Marking the same item again with the same name updates the slot.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `description` | `string` | no | Up to 200 characters. |
| `duration_policy` | `fit`, `stretch_timeline` | no | Media slots only. Default fit. |
| `item_id` | `string` | yes | A clip, audio, text or caption item. |
| `name` | `string` | yes | Matches [a-z][a-z0-9_]\{0,39\}; unique among the slots. |
| `required` | `boolean` | no | Default true. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "slot.mark",
  "args": {
    "description": "Headline",
    "item_id": "itm_s6t7v8w9x0",
    "name": "title"
  }
}
```
