Finds the marker at a frame and changes its frame (to) and or its label; a label of "" removes the label.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `at` | `string` | yes | The position of the marker to change. |
| `label` | `string` | no | The new label, up to 60 characters; "" removes it. |
| `to` | `string` | no | The new position. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "marker.set",
  "args": {
    "at": "12.5s",
    "label": "drop",
    "to": "13s"
  }
}
```
