Sets the given fields. hidden applies to visual tracks, the others to both kinds. locked refuses every edit of the items of the track (E_INVALID_STATE) until it is unlocked. solo plays only the soloed tracks: the picture of visual tracks when one is solo, and the sound of every track. volume is a factor from 0 to 4 on the volume of the items of the track; 1 clears it.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `hidden` | `boolean` | no | Visual tracks only. |
| `locked` | `boolean` | no | true refuses every edit of the items of the track until it is false again. |
| `muted` | `boolean` | no |  |
| `name` | `string` | no | The track name; "" clears it. |
| `solo` | `boolean` | no | true plays only the soloed tracks (the picture of visual tracks, the sound of all). |
| `track_id` | `string` | yes |  |
| `volume` | `number` | no | Factor on the volume of the items of the track, 0 to 4; 1 is neutral. min 0; max 4 |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "track.update",
  "args": {
    "hidden": true,
    "track_id": "trk_f6g7h8j9k0"
  }
}
```
