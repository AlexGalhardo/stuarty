Adds a marker the person or the agent keeps at a frame of the timeline (not of an item), with an optional label of up to 60 characters. At most 200 markers; one marker per frame. Markers have no effect on the picture or the sound. The beat markers of a music item are separate (audio.mark_beats).

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `at` | `string` | yes | The position on the timeline. |
| `label` | `string` | no | Up to 60 characters; default none. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "marker.add",
  "args": {
    "at": "12.5s",
    "label": "drop"
  }
}
```
