Sets the Gaussian blur radius in pixels at project resolution, 0 to 100; 0 removes the blur.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | A clip. |
| `radius` | `number` | yes | Blur radius in pixels, 0 to 100; 0 removes the blur. min 0; max 100 |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "clip.set_blur",
  "args": {
    "item_id": "itm_m1n2p3q4r5",
    "radius": 12.5
  }
}
```
