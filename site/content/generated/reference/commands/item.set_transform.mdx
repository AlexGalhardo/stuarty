Sets the given properties, rounded to 3 decimals. Scale 1, rotation 0 and opacity 1 clear the stored value. A property that has keyframes cannot be set; use keyframe.set or keyframe.clear.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_id` | `string` | A clip, text, caption or shape item. | A clip, text, caption or shape item. |
| `opacity` | `number` | 0 to 1. min 0; max 1 | 0 to 1. min 0; max 1 |
| `rotation` | `number` | Degrees clockwise. | Degrees clockwise. |
| `scale` | `number` | Uniform scale, greater than 0 and at most 20. max 20 | Uniform scale, greater than 0 and at most 20. max 20 |
| `x` | `number` | Centre of the item in pixels. | Centre of the item in pixels. |
| `y` | `number` | Centre of the item in pixels. | Centre of the item in pixels. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "item.set_transform",
  "args": {
    "item_id": "itm_s6t7v8w9x0",
    "scale": 1.5,
    "x": 540
  }
}
```
