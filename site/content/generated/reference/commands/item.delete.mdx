Removes the items. With ripple track, every later item on each affected track moves earlier by the length freed on that track; with ripple all, every later item on every track moves by the length freed, which requires the deleted items to cover one contiguous range.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_ids` | array of `string` | yes | at least 1 items; at most 200 items |
| `ripple` | `none`, `track`, `all` | no | none (default), track or all. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "item.delete",
  "args": {
    "item_ids": [
      "itm_a1b2c3d4e5"
    ],
    "ripple": "track"
  }
}
```
