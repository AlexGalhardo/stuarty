## You will learn

- how to create a project with a format that fits the platform;
- how to list and read projects;
- what the revision number means.

## The idea

A project is one JSON document: tracks, items, the assets it uses and its settings. Every change is a batch of operations that raises its `revision` by one, so a project always has a clean history you can undo.

## Quick start

<Tabs>
<Tab title="CLI">

```bash
vukem-video project:create --name "Launch teaser" --preset 9:16 --json
vukem-video project:list --json
vukem-video project:show prj_7k2m9x4q1b
```

</Tab>
<Tab title="MCP">

Call `project_create` with `{"name": "Launch teaser", "preset": "9:16"}`, then `project_list` and `project_get`.

</Tab>
<Tab title="HTTP">

`POST /api/v1/projects` with `{"name": "Launch teaser"}`, then `GET /api/v1/projects` and `GET /api/v1/projects/{id}`.

</Tab>
</Tabs>

The presets are `9:16` (the default, for short vertical video), `1:1`, `16:9` and `4:5`. The <Term id="frame-rate">frame rate</Term> defaults to 30 and can be `30000/1001`. A new project is at revision 0.

## Change the frame, the rate or the name later

| To | Operation |
| --- | --- |
| change the frame to another preset (`aspect`: `16:9` is 1920x1080, `9:16` is 1080x1920, `1:1` is 1080x1080, `4:5` is 1080x1350) or to a `width` and `height`, and **reframe** what is in it | `settings.reframe` |
| change the frame size, the background colour or the loudness target, without rescaling items | `settings.set` |
| change the frame rate (`"30"`, `"30000/1001"`, 1 to 120 fps) | `settings.set_fps` |
| rename the project | `project.rename` |

`settings.reframe` is the one to use when you turn a 16:9 video into a 9:16 one: the explicit position of the items and their keyframes follow the new size, and text, shapes and clips with fit `none` are scaled by the smaller of the two axis ratios, so they keep their share of the frame. Clips with fit `cover` or `contain` fill the frame by themselves; adjust their crop with `clip.set_framing` (see [Clip properties](/docs/guide/clip-properties)).

`settings.set_fps` rescales every time in the project to the new rate and then repairs what rounding can break (a duration that became 0, overlaps, keyframes, words, fades and transitions). The result lists every item it adjusted.

## Common mistakes

- Using a project id from another workspace. A project id looks like `prj_7k2m9x4q1b`; an unknown one is `E_NOT_FOUND`.
- Editing a trashed project. Restore it first with `project:restore`; the error is `E_INVALID_STATE`.
