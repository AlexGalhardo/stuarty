## The shortest path

1. [Install Stuarty](/docs/installation): on Windows, with Docker, or on a server.
2. Open the editor. In the desktop application it is the window; with `stuarty serve` run `stuarty open`.
3. [Make a vertical short with captions](/docs/guide/tutorial-vertical-short): import a clip, caption it and export a checked MP4.

## What you can do

- Import media, cut and arrange it on a timeline, add text and captions, and export a verified MP4.
- Save a project as a template and start new projects from it.
- Let an agent do the same through the MCP server or the CLI.

## For a person

1. Start the server (`stuarty serve`), or the desktop application.
2. Run `stuarty open`. It finds the running server of the workspace, wherever it listens, and opens the editor signed in with a one-time code. The plain address answers 401 until a browser has signed in this way (in network mode, open it and sign in with your account).

## For an agent

Pick one of three routes to the same project:

1. The stdio MCP server: the command is `stuarty mcp`.
2. The CLI with `--json`, for example `stuarty project:create --name "Launch teaser" --description "A 30 second vertical video for people who follow the channel, with captions and a thumbnail." --specific "Publish one video that explains the idea" --measurable "One hundred views in the first week" --achievable "The footage and the script exist" --relevant "It brings the first audience" --time-bound "Edit on Monday, publish on Tuesday" --due 2027-03-31 --json`.
3. The HTTP API of `stuarty serve`, with Streamable HTTP MCP at `POST /mcp`.

These routes share one set of operations, so an agent and a person see the same result. The [agents overview](/docs/agents/overview) shows how to connect one.
