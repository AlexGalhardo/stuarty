## You will learn

- how to add a <Term id="track">track</Term> and a <Term id="clip">clip</Term> in one batch;
- how to read the project cheaply;
- how to put markers on the timeline.

## Quick start

Add two tracks and a clip. The clip names the imported asset, where it starts on the timeline, where it starts in the source and how long it runs:

```json
{
  "project_id": "prj_7k2m9x4q1b",
  "base_revision": 1,
  "operations": [
    { "op": "track.add", "args": { "kind": "visual", "name": "Video", "id": "trk_f6g7h8j9k0" } },
    { "op": "clip.add", "args": {
      "track_id": "trk_f6g7h8j9k0", "asset_id": "ast_3c5v8n2w6d",
      "start": "0s", "source_in": "2s", "duration": "5s", "id": "itm_m1n2p3q4r5"
    } }
  ]
}
```

Send it with the `edit` MCP tool, `stuarty edit --project prj_7k2m9x4q1b --ops -` (the batch on standard input), or `POST /api/v1/projects/{id}/edit`. The result gives the new `revision`, the ids created and a `diff`.

Read the project back as text with `project_get` (or `project:show`). The concise view is meant to fit in two pages of a few thousand tokens even for a long project; follow `next_cursor` for the next page.

## Markers

A **<Term id="marker">marker</Term>** is a labelled point on the timeline. It changes neither the picture nor the sound: it only helps you (or an agent) find a place again.

| To | Operation |
| --- | --- |
| put a marker at a position (`at`), with an optional `label` of up to 60 characters | `marker.add` |
| move a marker (`to`) or change its label (an empty label removes it) | `marker.set` |
| remove the marker at a position, or every marker (`all`) | `marker.remove` |

```json
{ "op": "marker.add", "args": { "at": "12s", "label": "chorus" } }
```

In the editor, `M` adds a marker at the playhead, or removes the one there, and `Mod+Shift+Left` and `Mod+Shift+Right` jump to the previous and the next marker. The [audio page](/docs/guide/audio) shows how to mark the beats of a song.

## Common mistakes

- A clip longer than the asset, or a `source_in` past its end: `E_INVALID_TIME`.
- Two items on one track at the same time: `E_OVERLAP`.
