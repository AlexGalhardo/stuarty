## You will learn

- how to list the history and see who changed what;
- how to <Term id="undo-and-redo">undo</Term> and redo your own steps.

## Quick start

<Tabs>
<Tab title="CLI">

```bash
vukem-video history --project prj_7k2m9x4q1b
vukem-video undo --project prj_7k2m9x4q1b
vukem-video redo --project prj_7k2m9x4q1b
```

</Tab>
<Tab title="MCP">

The `history` tool with `action` set to `list`, `undo` or `redo`.

</Tab>
</Tabs>

Undo reverts the latest step of the caller that asks, not the latest step of anyone. If another actor changed the same thing since, the step is skipped and the result says why (`changed_by_other_actor`). Undo is itself a revision, so it can be undone.

## Common mistakes

- Nothing to undo: `E_NOTHING_TO_UNDO`. Nothing to redo: `E_NOTHING_TO_REDO`.
