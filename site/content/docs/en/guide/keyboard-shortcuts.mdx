## You will learn

- where the full list of shortcuts is;
- how to change a shortcut;
- how to reach any command without a shortcut.

## The idea

`Mod` is `Ctrl` on Windows and Linux and `Cmd` on macOS. A shortcut never fires while you type in a field, except `Mod+K`. Press `?` at any time to open the list inside the editor.

The full list, grouped by what the keys do and with the keys spelled out for Windows, Linux and macOS, is [All keyboard shortcuts](/docs/guide/keyboard-shortcuts-list). It is generated from the keymap of the editor, so it is always the list of the version you run.

Inside the timeline, the arrow keys move the focus between items, `Home` and `End` go to the first and last item of the track, and `Enter` activates the focused item.

## Change a shortcut

Nine shortcuts can be changed: split (`Mod+B`), the two trims (`Q` and `W`), add caption (`C`), add text (`T`), snapping (`N`) and the three timeline zooms. Press `?`, choose the key of the row, then press the new one. `Esc` cancels. A key that another row already uses, and `Tab` and `Enter`, are refused. **Reset to defaults** restores them all.

## Quick start

Press `Mod+K`. The palette lists every command of the product with a form built from its arguments. Type part of a name, such as `crossfade`, choose it, fill the form and confirm. Anything an agent can do, you can do from here.

An agent has no keyboard: it sends the same commands with `stuarty edit` or the `edit` tool. See [Commands, batches and revisions](/docs/concepts/commands-and-revisions).

## Common mistakes

- Pressing `Q` or `W` while a text field is focused: it types the letter. Click the timeline first.
- Using `Alt+1` with `Ctrl` held: the browser owns that combination. Use `Alt` alone.
- Looking for `S` to split: split is `Mod+B` (you can rebind it).
