Adds a copy of the item at start, on the same track or another track of the same kind. Keyframes, words and the name are copied; the slot mark is not. It fails when the copy would overlap an item of the target track.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `item_id` | `string` | yes | The item to copy. |
| `new_id` | `string` | no | The id of the copy. |
| `start` | `string` | yes | Absolute start of the copy. |
| `track_id` | `string` | no | The track of the copy; default the source's track. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "item.duplicate",
  "args": {
    "item_id": "itm_m1n2p3q4r5",
    "new_id": "itm_s6t7v8w9x0",
    "start": "3s"
  }
}
```
