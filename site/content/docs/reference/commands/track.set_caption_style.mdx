Sets the caption style of a visual track. The style is stored exactly as given, including keys equal to the default. A null value removes a key when merging. In this build highlight accepts only "none".

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `replace` | `boolean` | no | Replace the whole style instead of merging. |
| `style` | `object` | yes | A partial CaptionStyle; null removes a key when merging. |
| `track_id` | `string` | yes |  |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "track.set_caption_style",
  "args": {
    "style": {
      "position": "middle",
      "size": 72
    },
    "track_id": "trk_a1b2c3d4e5"
  }
}
```
