Removes the asset from the project. It fails with E_IN_USE, listing the items, while an item uses it. The file stays in the content store.

## Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `asset_id` | `string` | yes | The id of the asset to remove. |

## Example

As one operation of an `edit` batch (the `edit` tool of MCP, `vukem-video edit --ops`, or `POST /api/v1/projects/{id}/edit`):

```json
{
  "op": "asset.remove",
  "args": {
    "asset_id": "ast_3c5v8n2w6d"
  }
}
```

## Errors

[`E_VALIDATION`](/docs/reference/error-codes#e_validation), [`E_NOT_FOUND`](/docs/reference/error-codes#e_not_found), [`E_IN_USE`](/docs/reference/error-codes#e_in_use)

## Scope and phase

Scope `media`, phase `alpha`. Run `vukem-video command:help asset.remove` for the same description from the binary.
