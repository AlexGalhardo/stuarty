## O que você vai aprender

- como os silêncios são encontrados e como o corte é feito;
- quais configurações o controlam;
- como remover silêncios com um comando.

## A ideia

Quando uma mídia de vídeo é importada, o produto analisa o seu áudio e registra onde o som cai abaixo de um nível de ruído. A **remoção de silêncio** substitui um clipe por um clipe para cada trecho de fala e, por padrão, fecha os espaços, de modo que os itens seguintes da faixa andam para antes. A fala nunca é cortada a seco: um pouco de **margem** permanece de cada lado de cada corte.

| Configuração | Padrão | Significado |
| --- | --- | --- |
| `threshold_db` | `-35` | Nível de ruído do silêncio: -30, -35, -40 ou -45 |
| `min_silence` | `0.4s` | Silêncios mais curtos que isso são mantidos |
| `padding` | `0.1s` | Fala mantida em volta de cada corte |
| `ripple` | `track` | `track` fecha os espaços, `none` os deixa |

O comando nunca inicia uma análise sozinho: o serviço fornece os silêncios da mídia. Leia-os antes com `media_inspect` e a seção `silences`. A remoção de silêncio ainda não tem uma seção no inspetor: use a paleta de comandos (`Ctrl+K`, `Cmd+K` no macOS), a CLI ou um agente. O corte inteiro é um único passo de desfazer.

## Início rápido

<Tabs>
<Tab title="CLI">

```bash
vukem-video media:inspect ast_4h6j8k2m3n --project prj_7k2m9x4q1b --sections silences
vukem-video edit --project prj_7k2m9x4q1b clip.remove_silences item_id=itm_m1n2p3q4r5 \
  min_silence=0.5s threshold_db:=-40
```

</Tab>
<Tab title="MCP">

`media_inspect` com `{"project_id": "prj_7k2m9x4q1b", "asset_id": "ast_4h6j8k2m3n", "sections": ["silences"]}`, depois `edit` com:

```json
{ "op": "clip.remove_silences", "args": { "item_id": "itm_m1n2p3q4r5", "min_silence": "0.5s" } }
```

</Tab>
</Tabs>

Use `dry_run` para ver os pedaços antes de salvar, e `view` com uma folha de contato para conferir o resultado.

## Erros comuns

- Usá-lo em um clipe de uma mídia sem áudio: o comando é recusado.
- Um limiar que não é um dos quatro valores: `E_VALIDATION`.
- Esperar que as legendas do clipe acompanhem o corte. Ressincronize-as com `caption.retime_from_clip`.
