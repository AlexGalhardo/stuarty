## O que você vai aprender

- como conectar um agente e o que ele pode fazer;
- a ordem em que um bom agente trabalha e os comandos que ele executa;
- como você confere o trabalho dele.

## A ideia

O agente usa os mesmos comandos que você. Pelo MCP, ele chama ferramentas como `edit`, `lint` e `view`; com um shell, ele executa as mesmas operações pela CLI. Toda edição é uma revisão numerada com o nome do agente, então você pode ler o histórico e desfazer qualquer passo. Nada é enviado pela rede pelo próprio produto.

## Passos

1. Conecte o agente. Para o Claude Code:

   ```bash
   claude mcp add vukem-video -- vukem-video mcp
   ```

   Outros clientes aceitam o mesmo comando, veja [Conecte um agente](/docs/agents/connect). Se você executa o editor, o agente e o navegador compartilham o projeto.

2. Ensine o produto a ele. O `vukem-video agent:docs --print skill` imprime a skill e o `--print agents` o trecho para o seu `AGENTS.md`; veja [A skill](/docs/agents/skill).

3. Peça em palavras simples, por exemplo: "Importe `interview.mp4`, remova os silêncios, legende a fala e exporte um vídeo 9:16."

4. O agente trabalha nesta ordem. Você pode acompanhá-lo no histórico.

   | Passo | Ferramenta MCP | CLI |
   | --- | --- | --- |
   | criar o projeto | `project_create` | `vukem-video project:create --name "Interview" --id prj_7k2m9x4q1b` |
   | importar a mídia | `media_import` | `vukem-video media:import interview.mp4 --project prj_7k2m9x4q1b --asset-id ast_3c5v8n2w6d` |
   | aprender as operações | `command_help` | `vukem-video command:help clip.add` |
   | editar em um lote | `edit` | `vukem-video edit --project prj_7k2m9x4q1b --ops -` |
   | transcrever | `job_start` com `"kind": "transcribe"` | `vukem-video transcribe --project prj_7k2m9x4q1b --asset ast_3c5v8n2w6d --wait` |
   | conferir | `lint`, depois `view` | `vukem-video lint --project prj_7k2m9x4q1b` |
   | exportar | `job_start` com `"kind": "export"` | `vukem-video export --project prj_7k2m9x4q1b` |

5. Leia o que ele fez. O agente vê o mesmo histórico que você:

   ```bash
   vukem-video history --project prj_7k2m9x4q1b
   ```

6. Desfaça o que você não gostar. O `vukem-video undo --project prj_7k2m9x4q1b` reverte o último passo, e o agente pode refazer ou tentar de novo.

## Como conferir o trabalho dele

Um agente deve olhar do jeito mais barato primeiro: ler o projeto como texto, executar `lint`, depois olhar quadros com `view`. [Como um agente verifica o próprio trabalho](/docs/agents/verify) explica a ordem. Peça ao agente que execute `lint` antes de cada exportação; a exportação é recusada enquanto a verificação encontrar um erro.

## Erros comuns

- Deixar dois atores editarem a partir de uma revisão antiga: `E_REVISION_CONFLICT`. O agente lê o projeto de novo e planeja de novo; veja [Receitas](/docs/agents/recipes).
- Pedir a transcrição antes de o auxiliar estar instalado. Uma pessoa o instala uma vez com `vukem-video tools:install whisper`.
- Dar ao agente um caminho em outra máquina. Os caminhos são lidos na máquina que roda o servidor.
