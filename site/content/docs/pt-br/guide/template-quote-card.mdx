## O que você vai aprender

- o que o ponto de partida contém;
- como preencher a citação e o autor;
- como mudar as cores.

## A ideia

O **Cartão de citação** é um projeto de 1080 x 1080 de 6 segundos: um fundo cor de papel, uma barra de destaque curta, a citação em uma fonte com serifa e o autor em letras maiúsculas, ambos surgindo subindo. As cores do modelo são `paper` (`#F4EFE6`, o fundo), `ink` (`#1B1B1B`, a citação) e `accent` (`#B5452A`, a barra e o autor).

| Espaço | Tipo | O que vai nele |
| --- | --- | --- |
| `quote` | texto | a citação (padrão `A quote worth sharing goes here.`) |
| `author` | texto | quem a disse (padrão `Author Name`) |

## Início rápido

<Tabs>
<Tab title="CLI">

```bash
cat > fill.json <<'EOF'
{ "quote": { "text": "Make it work, then make it small." }, "author": { "text": "A. Writer" } }
EOF
vukem-video template:new tpl_5n8b2v6c1x --name "Quote 01" --fill fill.json
```

</Tab>
<Tab title="MCP">

`template` com `{"action": "new", "template_id": "tpl_5n8b2v6c1x", "name": "Quote 01", "fill": {"quote": {"text": "Make it work, then make it small."}, "author": {"text": "A. Writer"}}}`.

</Tab>
</Tabs>

Para mudar as cores do cartão, altere as cores nomeadas do novo projeto com `template.set_info`: `{"colors": {"paper": "#101820", "ink": "#FFFFFF"}}`. Todo item que usa `$paper` ou `$ink` acompanha.

## Erros comuns

- Citações longas: o texto quebra em uma largura máxima, e uma citação que cresce para fora da área segura é informada como `L_SAFE_AREA`. Encurte-a ou diminua o tamanho com `text.set`.
- Remover uma cor que um item ainda usa como `$name`: recusado.
