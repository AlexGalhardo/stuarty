## O que você vai aprender

- quais configurações pertencem a um projeto e como mudá-las;
- quais configurações pertencem a você, no editor;
- onde ficam as configurações do servidor.

## A ideia

Há três níveis de configurações, mantidos separados de propósito.

As **configurações do projeto** fazem parte do projeto e do seu histórico, então toda mudança pode ser desfeita: o `width` e o `height` do quadro (números pares, de 16 a 4096), a taxa de quadros, a cor de `background` (uma cor hexadecimal ou uma cor do modelo como `$paper`) e o `loudness_target` em LUFS (-30 a -5). Mudar a taxa de quadros reescala todos os tempos do projeto e repara o que o arredondamento quebra, como uma duração que virou zero; o resultado lista cada item que ele ajustou. O nome do projeto é mudado com `project.rename`. Os projetos novos partem de uma predefinição: 9:16, 1:1, 16:9 ou 4:5.

As **preferências do editor** são suas e ficam no navegador: o idioma (inglês ou português do Brasil), escolhido na página de projetos, e o tema claro ou escuro, que tem um botão na página de projetos e na barra superior do editor. A troca de idioma muda apenas o editor; o texto da CLI e do MCP continua em inglês.

As **configurações do servidor** são variáveis de ambiente lidas na inicialização, como o codificador, os limites e o modo. Elas estão listadas em [Variáveis de configuração](/docs/reference/configuration). Mudar uma exige reiniciar.

Não há uma página de configurações nesta versão: as configurações do projeto são mudadas com a paleta de comandos (`Ctrl+K`, `Cmd+K` no macOS), a CLI ou um agente.

## Início rápido

<Tabs>
<Tab title="CLI">

```bash
vukem-video edit --project prj_7k2m9x4q1b settings.set background=#101820 width:=1080 height:=1920
vukem-video edit --project prj_7k2m9x4q1b settings.set_fps fps=30000/1001
vukem-video edit --project prj_7k2m9x4q1b project.rename name="Launch teaser v2"
```

</Tab>
<Tab title="MCP">

`edit` com as operações:

```json
{ "op": "settings.set", "args": { "background": "#101820", "loudness_target": -16 } }
{ "op": "settings.set_fps", "args": { "fps": "30" } }
```

</Tab>
</Tabs>

## Erros comuns

- Um tamanho de quadro ímpar: `E_VALIDATION`. Larguras e alturas precisam ser pares.
- Mudar a taxa de quadros no fim do trabalho. Todos os tempos são reescalados; confira a lista `adjusted` e execute `lint`.
- Procurar no editor uma configuração do servidor, como um limite. Essas são variáveis de ambiente.
