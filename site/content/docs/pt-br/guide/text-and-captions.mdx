## O que você vai aprender

- como adicionar um item de texto e editá-lo;
- como uma faixa de legendas é estilizada.

## A ideia

Um item de **texto** mostra uma string durante um intervalo. Uma **legenda** é um texto com tempo por palavra em uma faixa de legendas, com o estilo definido na faixa. As regras de verificação conferem que o texto fica dentro da área segura do formato.

## Início rápido

```json
{ "op": "text.add", "args": {
  "track_id": "trk_a1b2c3d4e5", "start": "0s", "duration": "3s", "text": "Launch day"
} }
```

Mude o texto depois com `text.set`. Estilize uma faixa de legendas com `track.set_caption_style`.

## Erros comuns

- Colocar texto em uma faixa de áudio: `E_TYPE_MISMATCH`.
- Texto que sai da área segura: um aviso da verificação, não um erro. Execute o `lint` antes de exportar.
