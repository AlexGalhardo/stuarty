## A ideia

Cada receita é uma sequência de comandos da CLI que funciona como está escrita. As mesmas operações existem como ferramentas MCP; os lotes são o mesmo JSON. Troque os identificadores pelos que os seus comandos imprimem, ou passe os seus com `--id` e `--asset-id` como abaixo.

## Importar, cortar, legendar e exportar

```bash
vukem-video project:create --name "Teaser" --id prj_7k2m9x4q1b
vukem-video media:import clip.mp4 --project prj_7k2m9x4q1b --asset-id ast_3c5v8n2w6d
vukem-video edit --project prj_7k2m9x4q1b --ops - <<'EOF'
[{"op":"track.add","args":{"kind":"visual","name":"Video","id":"trk_f6g7h8j9k0"}},
 {"op":"track.add","args":{"kind":"visual","name":"Captions","id":"trk_a1b2c3d4e5"}},
 {"op":"clip.add","args":{"track_id":"trk_f6g7h8j9k0","asset_id":"ast_3c5v8n2w6d","start":"0s","duration":"2s","id":"itm_m1n2p3q4r5"}}]
EOF
vukem-video edit --project prj_7k2m9x4q1b --ops - <<'EOF'
[{"op":"item.split","args":{"item_id":"itm_m1n2p3q4r5","at":"1s","new_id":"itm_c3d4e5f6g7"}},
 {"op":"item.delete","args":{"item_ids":["itm_c3d4e5f6g7"]}}]
EOF
vukem-video edit --project prj_7k2m9x4q1b --ops - <<'EOF'
[{"op":"caption.add","args":{"track_id":"trk_a1b2c3d4e5","start":"0.1s","linked_item":"itm_m1n2p3q4r5","id":"itm_s6t7v8w9x0","words":[{"text":"Meet","start":"0s","duration":"0.3s"},{"text":"us.","start":"0.3s","duration":"0.3s"}]}}]
EOF
vukem-video lint --project prj_7k2m9x4q1b
vukem-video export --project prj_7k2m9x4q1b
```

O `lint` antes do `export` pega o que bloquearia a exportação. O `export` espera pela tarefa e imprime o resultado verificado.

Para legendar a fala em vez de digitar as palavras, veja "Legendas a partir de uma transcrição" abaixo.

## Recupere-se de um conflito

Quando outro ator mudou o projeto depois do seu plano, uma edição com um `--base` desatualizado falha com `E_REVISION_CONFLICT` e código de saída `2`. Aqui o projeto está na revisão 1 e outro ator muda antes a faixa, o que o leva à revisão 2.

```bash
vukem-video edit --project prj_7k2m9x4q1b --actor other track.update track_id=trk_f6g7h8j9k0 name=Theirs
vukem-video edit --project prj_7k2m9x4q1b --base 1 track.update track_id=trk_f6g7h8j9k0 name=Mine
# exit 2: E_REVISION_CONFLICT, details.diff lists what changed since revision 1
vukem-video project:show prj_7k2m9x4q1b
vukem-video edit --project prj_7k2m9x4q1b --base 2 track.update track_id=trk_f6g7h8j9k0 name=Mine
```

Leia o `details.diff`, planeje de novo contra a revisão atual e envie o lote de novo. O lote que falhou não mudou nada.

## Preencha um modelo

O projeto precisa ter um item de texto marcado como espaço (aqui `headline`) antes de ser salvo como modelo.

```bash
vukem-video edit --project prj_7k2m9x4q1b --base 1 slot.mark item_id=itm_t1t2t3t4t5 name=headline
vukem-video template:save --project prj_7k2m9x4q1b --name "Spring sale"
vukem-video template:new <template id> --name "Spring sale" --id prj_6t4y2w8j1m --fill - <<'EOF'
{"headline":{"text":"Spring sale"}}
EOF
vukem-video export --project prj_6t4y2w8j1m
```

Um espaço obrigatório que falta devolve um erro que nomeia o espaço em `path`; corrija o preenchimento e execute o comando de novo.

## Legendas a partir de uma transcrição

O `transcribe` precisa do auxiliar de transcrição, instalado uma vez por uma pessoa com `vukem-video tools:install whisper`. O projeto tem um clipe `itm_m1n2p3q4r5` em uma faixa de vídeo e uma faixa vazia `trk_a1b2c3d4e5` para as legendas.

```bash
vukem-video transcribe --project prj_7k2m9x4q1b --asset ast_3c5v8n2w6d --language en --wait
vukem-video edit --project prj_7k2m9x4q1b caption.from_transcript clip_item_id=itm_m1n2p3q4r5 track_id=trk_a1b2c3d4e5 new_ids:='["itm_c1c2c3c4c5","itm_c6c7c8c9c0"]'
```

Passe um id novo por linha de legenda.

## Remova silêncios

Com a transcrição da mídia no lugar, corte as partes silenciosas de um clipe.

```bash
vukem-video edit --project prj_7k2m9x4q1b clip.remove_silences item_id=itm_m1n2p3q4r5 new_ids:='["itm_s1s2s3s4s5","itm_s6s7s8s9s0"]'
```

Passe um id novo por pedaço que sobra; o `vukem-video media:inspect --sections silences` os lista.

## Erros comuns

- Planejar a partir de uma revisão desatualizada. Leia o projeto de novo depois de qualquer conflito.
- Pular o `lint`. O portão da exportação recusa um projeto com erros de verificação.
