## O que você vai aprender

- como criar um projeto com um formato adequado à plataforma;
- como listar e ler projetos;
- o que significa o número da revisão.

## A ideia

Um projeto é um único documento JSON: faixas, itens, as mídias que ele usa e suas configurações. Toda mudança é um lote de operações que aumenta a sua `revision` em um, então um projeto sempre tem um histórico limpo que você pode desfazer.

## Início rápido

<Tabs>
<Tab title="CLI">

```bash
vukem-video project:create --name "Launch teaser" --preset 9:16 --json
vukem-video project:list --json
vukem-video project:show prj_7k2m9x4q1b
```

</Tab>
<Tab title="MCP">

Chame `project_create` com `{"name": "Launch teaser", "preset": "9:16"}`, depois `project_list` e `project_get`.

</Tab>
<Tab title="HTTP">

`POST /api/v1/projects` com `{"name": "Launch teaser"}`, depois `GET /api/v1/projects` e `GET /api/v1/projects/{id}`.

</Tab>
</Tabs>

As predefinições são `9:16` (o padrão, para vídeo vertical curto), `1:1`, `16:9` e `4:5`. A taxa de quadros padrão é 30 e pode ser `30000/1001`. Um projeto novo está na revisão 0.

## Erros comuns

- Usar o id de um projeto de outro espaço de trabalho. Um id de projeto se parece com `prj_7k2m9x4q1b`; um id desconhecido é `E_NOT_FOUND`.
- Editar um projeto que está na lixeira. Restaure-o antes com `project:restore`; o erro é `E_INVALID_STATE`.
