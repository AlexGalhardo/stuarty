<Callout type="warning" title="Versão inicial">
O Vukem Video está na fase de Protótipo. A primeira versão do editor, a `v0.2.0`, traz o servidor local, a imagem de contêiner e os instaladores, mas o editor ainda não edita vídeo. Partes dos comandos abaixo estão especificadas e ainda não funcionam.
</Callout>

## O que você pode fazer hoje

- Ler os documentos de planejamento no [repositório](https://github.com/AlexGalhardo/vukem-video/tree/main/docs): requisitos, decisões de arquitetura e especificações.
- Compilar o esqueleto do servidor a partir do código-fonte. Você precisa do Go (a versão do `go.mod`) e do Bun para o front-end. O servidor inicia e responde a uma verificação de saúde; ele ainda não edita vídeo.
- Acompanhar a página de [versões](https://github.com/AlexGalhardo/vukem-video/releases) e o [changelog](/changelog).

## Instalar

O produto roda apenas na sua máquina. Cada [versão](https://github.com/AlexGalhardo/vukem-video/releases) traz:

- instaladores do servidor local, que instalam o `vukem-video` e um atalho que inicia o servidor e abre o editor no navegador; desinstalar remove o programa e mantém o seu espaço de trabalho:
  - Windows 11: `vukem-video_<version>_windows_amd64_setup.exe`
  - Debian e Ubuntu: `vukem-video_<version>_linux_<arch>.deb`
  - qualquer Linux: `vukem-video_<version>_linux_amd64.AppImage`
  - macOS: `vukem-video_<version>_darwin_<arch>.pkg`
- arquivos compactados para seis plataformas e o `checksums.txt`, assinado com cosign.

A imagem de contêiner da versão web é iniciada com um comando deste formato, que publica a porta apenas no seu computador:

```bash
docker run --rm -p 127.0.0.1:7878:7878 -v vukem-video:/data \
  ghcr.io/alexgalhardo/vukem-video:<version>
```

O servidor escuta em `127.0.0.1:7878` e só pode ser acessado a partir do seu computador.

### Windows SmartScreen e macOS Gatekeeper

Os instaladores não são assinados com um certificado pago de assinatura de código, então os dois sistemas avisam antes da primeira execução.

- **Windows.** O SmartScreen mostra "O Windows protegeu seu PC" para o `.exe`. Escolha "Mais informações" e depois "Executar assim mesmo".
- **macOS.** O Gatekeeper diz que o pacote não pode ser aberto porque a Apple não consegue verificá-lo. Clique com Control no `.pkg` e escolha Abrir, ou permita em Ajustes do Sistema, Privacidade e Segurança.

Para conferir um download antes de executá-lo, verifique o `checksums.txt` com o cosign e compare o SHA-256 do arquivo, como descrito na [política de segurança](https://github.com/AlexGalhardo/vukem-video/blob/main/.github/SECURITY.md).

## Para uma pessoa

1. Inicie o servidor (`vukem-video serve`).
2. Abra `http://127.0.0.1:7878` no navegador, ou execute `vukem-video open`.

## Para um agente

Escolha uma entre três rotas para o mesmo projeto:

1. O servidor MCP por stdio: o comando é `vukem-video mcp`.
2. A CLI com `--json`, por exemplo `vukem-video project:create --name "Launch teaser" --json`.
3. A API HTTP do `vukem-video serve`, com MCP por Streamable HTTP em `POST /mcp`.

Essas rotas estão especificadas no repositório (SDD-003); partes delas ainda não foram implementadas.
