## Product and architecture direction options (for maintainer prioritization)

These are forward-looking strategic tracks grounded directly in repository PRDs, ADRs, and open roadmap epics (best initiated via design/spike plans when prioritized):

1. **`DIR-01` — Complete "One Renderer Everywhere" (Epic 47)**: Once Plan 010 closes NFR-061 (`s_export <= 2.00 s`) and idle playback benchmarks confirm browser budgets on Windows + macOS, flip `DEFAULT_EXECUTOR` (`web/resources/js/editor/preview/executorChoice.ts:17`) and `STUARTY_EXPORT_RENDERER` (`engine/export/job.go:77-79`) to `"rust"`, retire `engine/compositor/` + `pixi.js`, and unlock gradient/rounded-corner recording backgrounds (`docs/sdds/025-screen-recording.md:485`). *Effort: L; Trade-off: verify WebView2/WKWebView/WebKitGTK playback latency before deleting PixiJS.*
2. **`DIR-02` — Ship last-mile self-contained distribution milestones**: Publish and pin the own LGPL FFmpeg build (`.config/ffmpeg.env`, Epic 98 tasks 5–6), publish and pin `stuarty-aihelper` (`engine/aihost/manifest.json:10-23`, currently `"published": false`, unlocking face-aware vertical cuts for real users), and execute Epic 43 (macOS desktop verification) + Epic 67 task 1 (ScreenCaptureKit ad-hoc signing spike on macOS). *Effort: M–L; Trade-off: macOS permission persistence across updates may require an Apple Developer ID decision.*
3. **`DIR-03` — Close the creator learning loop with opt-in Post Metrics (Epic 45)**: Add the optional `Metrics` capability on `service/social/` (YouTube, Instagram, Facebook), `metric_snapshots`, decaying polling in `service/publish/scheduler.go`, and `production-retro` skill integration (`docs/plans/45-post-metrics.md`). *Effort: M; Trade-off: spike OAuth read-metric scopes on unverified personal developer apps first (ADR-0035) and keep strictly opt-in (ADR-0032).*
4. **`DIR-04` — Unify the asymmetric AI provider matrix**: `service/providers/openai/` is currently the sole provider for image, voice, and image-edit, while `service/providers/google/` already authenticates against Gemini v1beta (`/models`) yet only implements `video`. Extending Google to text/image and adding a first-class loopback OpenAI-compatible preset (Ollama/llama.cpp/vLLM with `$0` cost and optional empty key, preserving loopback-only HTTP rules in `service/connections/connections.go:207`) removes single-provider lock-in. *Effort: M; Trade-off: maintainer product priority.*
5. **`DIR-05` — Close remaining v1.0 quality and trust gates (Epics 38, 42, 72)**: Execute the small-model `first-flow` benchmark pilot (`docs/agent-benchmark.md:104-120`, requires author `--estimate` budget approval), complete the zero-context security review (`docs/security-review-stuarty.md`) + 4-hour soak + Linux `no-egress.sh` check (Epic 42), and spike Depth-Anything-V2 Small (Apache-2.0, already licence-approved by ADR-0050, decoupled from BEN2) once `stuarty-aihelper` is published. *Effort: M–L.*
